# ViNG：用视觉目标学习开放世界导航

> **论文**：*ViNG: Learning Open-World Navigation with Visual Goals*
> **作者**：Dhruv Shah（UC Berkeley）、Benjamin Eysenbach（CMU）、Gregory Kahn、Nicholas Rhinehart、Sergey Levine（UC Berkeley）
> **发表**：ICRA 2021（pp. 13215–13222）
> **arXiv**：https://arxiv.org/abs/2012.09812（v1 2020-12-17，v2 2021-03-26）
> **项目主页**：https://sites.google.com/view/ving-robot

---

## 摘要

ViNG 是 UC Berkeley 提出的**视觉目标导航（Visual Goal Navigation）系统**：用户给机器人一张目的地照片，机器人仅凭单目前视相机和一份**离线采集**的历史轨迹数据，就能在户外非结构化环境中自主导航到目标，全程不需要 GPS、几何地图、仿真器或在线数据收集。

它的核心设计是"**学习的拓扑图 + 图搜索规划 + 学习的目标条件控制器**"三层组合：

1. **动力学距离函数 T**：预测两张观测图像之间需要多少时间步才能互相到达，把"可通行性"完全从数据中学出来，不做几何假设；
2. **拓扑图规划**：把历史观测建成非几何拓扑图，用 Dijkstra 搜索通往目标的最短路径，输出下一个途经点；
3. **相对位姿控制器**：预测当前观测与途经点之间的相对位姿，用 PD 控制器跟踪。

三个关键洞察——**负样本挖掘（negative mining）、图剪枝（graph pruning）、途经点提议（waypoint proposal）**——使 ViNG 成为第一个能纯靠离线真实数据学会长程视觉导航并部署在真实机器人上的系统。在 40 小时离线数据上训练后，ViNG 对 40 米以上的目标仍保持 86% 成功率，显著优于 SPTM、off-SoRB 等基线；在新环境中仅用 20~60 分钟数据即可适配，并能通过自我练习持续提升。

## 一、研究背景与问题定义

### 1.1 为什么需要学习式导航？

视觉导航在复杂环境中面临四个挑战：

- **动力学与环境交互难以精确建模**（高草可以穿过，墙不行，但几何上难以区分）；
- **高维观测**（图像）难以直接用于传统规划；
- **数据采集的成本与安全约束**要求从历史（离线）数据中学习；
- **跨环境泛化**困难。

传统的"建图 + 规划"流水线依赖 LiDAR、精确定位等结构化信息，且假设几何可通行性可以从观测中直接读出——但图 2 中的例子表明这个假设在真实世界经常失效：高草和斜坡岩石可通行，而被枯叶填平的坑不可通行，这些都无法从纯几何判断。

### 1.2 目标怎么给？—— 用一张照片

在没有 GPS 和地图的前提下，连"目标"本身都难以用坐标指定。ViNG 采用了一种自然的方案：**用户拍一张目的地的照片 `o_G`，机器人导航到拍摄这张照片的位置**。这模仿了人类依靠地标和"心理地图"导航的方式——不预设任何场景几何知识，同时提供了完成任务所需的全部信息。

### 1.3 问题形式化

- **输入**：目标图像 `o_G` + 若干条历史轨迹（人遥操作、自主探索甚至随机游走均可），每条轨迹是机载相机记录的稠密观测序列 `o_1, o_2, ..., o_n`；
- **输出**：连续的线速度与角速度指令；
- **约束**：单目相机、无状态估计（部分可观测 POMDP）、无空间地图，且要**自己判断何时已到达目标**。

### 1.4 与相关工作的关系

ViNG 属于"规划 + 学习"混合路线（SPTM、SoRB、PRM-RL、LSTN 一支）：用学习解决短程问题，用非几何拓扑图上的精确规划解决长程问题。但先前方法都有限制性假设：

| 方法 | 限制性假设 |
|---|---|
| LSTN | 需要照片级仿真复刻环境，~1.5M 样本 |
| PRM-RL | 需要 3D 运动学仿真器 + 真实世界 rollout 建 PRM |
| SPTM / SoRB | 简化动作空间，或需要在线数据收集 |

ViNG 的差异在于：**不使用仿真器、不需要在线交互、直接在离线真实数据上训练、处理高维图像并输出连续动作**。论文声称这是第一个在真实地面机器人上展示"从离线数据学习到达视觉目标的长程导航"的系统。

## 二、系统平台与数据

### 2.1 机器人平台

- **Clearpath Jackal UGV**：小型、快速、防水的户外地面机器人，适合城市与越野环境；
- **传感器**：前视 170° 广角相机（唯一用于方法的传感器）、6-DoF IMU、GPS、轮式编码器、RPLIDAR 2D 激光；
- **计算**：NVIDIA Jetson TX2（机载）；
- **注意**：GPS 和激光雷达**仅作为数据采集时的安全机制**，方法本身只使用相机图像。

### 2.2 数据：40 小时、10 个月前的离线数据

核心实验完全使用先前工作（BADGR）采集的数据——**40 小时，采集时间早于实验 10 个月以上**。数据与评估环境之间存在显著的季节、光照、时段差异，这要求算法必须丢弃外观等无关变化模式，建立跨季节、跨时段的对应关系。泛化实验另采集了少量新环境数据（同一套自监督采集策略）。

## 三、方法

ViNG 分为**训练**和**部署**两个阶段。

### 3.1 训练阶段：学习两个函数

#### 动力学距离 / 可通行性函数 T

学习一个函数 `T(o_i, o_j) ∈ R+`，预测"任意控制器从观测 `o_i` 导航到观测 `o_j` 所需的时间步数"。关键点是它必须封装**超越几何的物理知识**——高草和灌木视觉上相似，但草可穿行而灌木不行。

论文探索了两种训练方式：

- **监督学习**：从同一轨迹中取观测对 `(o_i, o_j)`，回归其间经过的时间步 `d_ij = j − i`。简单，但对应的是"行为策略的距离"，可能高估最短路径；
- **TD 学习**：理论上收敛到最短路径距离，但实验显示两者性能差别不大（见消融表）。

#### 相对位姿预测器 P

学习 `P(o_i, o_j)`，预测两张观测之间的相对位姿 `∆p`。训练标签来自车载里程计：对轨迹中相近的观测对，用里程计估计相对位姿 `∆p_ij` 作为监督信号。

#### 关键洞察 1：负样本挖掘（Negative Mining）

只用同一轨迹内的观测对训练 T 效果很差。根因是**分布偏移**：建拓扑图时，T 必须在来自**不同轨迹、不同时段**的观测对上求值，而训练时它只见过同轨迹内的正样本对。

解法：构造负样本集 `D−`——从**不同轨迹**采样观测对，统一标记为最大距离 `d_max`。这个增强对 T 的成功训练至关重要，带来了相对先前方法的显著提升。

```
训练数据构造：
D+ = {(o_i, o_j, d = min(j−i, d_max))}   同轨迹，i ≤ j
D− = {(o_i, o_j, d = d_max)}             跨轨迹（负样本）
```

### 3.2 部署阶段：拓扑图 + 规划 + 控制

#### 拓扑图构建

用学好的距离函数 T 把历史观测组织成有向图 M：

- **节点** = 历史观测图像（不关联任何世界坐标，图是非几何的）；
- **边权** = T 预测的可通行性/距离。

#### 关键洞察 2：图剪枝（Graph Pruning）

随着经验积累，全连接图的规模随节点数**平方增长**，既冗余又不可行。剪枝策略：

> **容易通行的边不加进图**（`T(o_i, o_j) < δ_sparsify` 的边被跳过）——因为这些边控制器大概率能直接走过去，不需要规划层操心。

#### 关键洞察 3：途经点提议（Waypoint Proposal）与控制器设计

规划输出的是"下一个途经点观测"（图像），控制器要把它变成动作。ViNG 的解法：

```
P(o_t, o_w) → 途经点相对位姿 ∆p → PD 控制器 → 速度指令
```

即以**途经点为中层的分层动作空间**：规划器负责"去哪儿"（图像级的途经点），相对位姿预测器 + PD 控制器负责"怎么去"。消融实验证明这个设计是长程性能的关键（见 5.4）。

#### 完整部署流程（Algorithm 2）

```
输入: 当前图像 o_t, 目标图像 o_G, 拓扑图 M
1. 用 T 的距离把 o_t, o_G 接入图 M（连到各自"最可通行"的邻居）
2. 加权 Dijkstra 搜索: o_w1, o_w2, ... ← Dijkstra(start=o_t, goal=o_G, M)
3. 估计第一个途经点的相对位姿: ∆p ← P(o_t, o_w1)
4. u_t ← PD-Controller(∆p)
5. 输出控制 u_t
```

### 3.3 实现细节

| 项目 | 配置 |
|---|---|
| 输入 | 两帧连续 RGB 图像堆叠，160×120 分辨率 |
| 编码器 | MobileNet（T 和 P 共享），1024 维特征 |
| T 输出头 | 3 层全连接 → 50 类距离分箱（d_max = 50），交叉熵损失 |
| P 输出头 | 3 层全连接 → 相对位姿回归，ℓ2 损失 |
| 优化 | batch 128，Adam，lr = 1e-4 |

## 四、实验

实验回答三个问题：

- **Q1**：在离线数据设定下，ViNG 与先前方法相比如何？
- **Q2**：ViNG 能否泛化到全新环境？能否边运行边适配？
- **Q3**：控制器有哪些替代设计，与本文选择相比如何？

### 4.1 Q1：离线数据的视觉目标导航

**设置**：真实户外环境（城市 + 越野），40 小时离线数据训练，6 组 {起点, 目标} 图像对，每组 3 次试验。成功指标 = 成功完成的专家轨迹比例。

**基线**：

| 基线 | 说明 |
|---|---|
| SPTM | 稠密拓扑图 + 观测对到电机指令的监督学习控制器 |
| off-SoRB | SoRB 的离线变体，拓扑图 + 离线 RL 学分布式 Q 函数 |
| State Estimator | 回归观测到真值位姿 (x, y, θ) + 位置控制器（**有 GPS 特权信息**，ViNG 没有） |
| Random | 随机游走 |

**结果**（图 3、图 4）：

- 所有非随机方法都能到达**近距离**目标，但 **40 米以上的目标只有 ViNG 能到达**，最难任务上成功率 86%；
- off-SoRB 近处尚可，远处失败——其拓扑图出现大量不连通分量，论文归因于离线数据下 Q 函数训练困难；
- SPTM（监督学习代替 Q 学习）在短程有效、长程优于 off-SoRB，但全距离段都不如 ViNG，尤其 30 米以上——提升正来自负样本挖掘与图剪枝；
- State Estimator 不具反应性，无法避碰，远程目标表现差。

### 4.2 Q2：泛化与在线自适应

**设置**：4 个与训练环境**截然不同**的新环境（barracks / industrial / park / tall grass）。先由人遥操作采集初始探索数据，随后机器人**自主练习**——随机采样一张见过的图像作为目标，用 ViNG 尝试到达；每轮结束后用新环境的全部经验（专家 + 自采轨迹）微调 T 和 P（即 **ViNG-Finetune**）。

**结果**（Table I，新环境成功率）：

| 环境 | ViNG-Source | ViNG-Target | ViNG-Finetune | SPTM-Finetune |
|---|---:|---:|---:|---:|
| barracks | 0.27 | 0.42 | **0.96** | 0.74 |
| industrial | 0.13 | 0.44 | **0.84** | 0.68 |
| park | 0.04 | 0.32 | **0.82** | 0.71 |
| tall grass | 0 | 0.38 | **0.79** | 0.56 |

- **ViNG-Source**（不吸收新环境经验）几乎完全失败，说明跨环境直接迁移不可行；
- **ViNG-Target**（只用新环境数据从头学）也不足；
- **ViNG-Finetune**（新旧经验结合）仅用 60 分钟新数据就达到 0.79~0.96；
- 学习曲线（图 6）显示性能随自主练习时长（0 → 20 → 60 分钟）持续提升——**自我改进系统**；
- ViNG-Finetune 优于 SPTM-Finetune，论文归因于 ViNG 额外的层次化结构。

### 4.3 与在线方法的对比（仿真）

真实世界无法承受在线 RL 的样本消耗，此实验在 Unity 照片级户外仿真器中进行：

- **PPO**：即使有 200 小时在线经验也表现很差——单一反应式策略不足以解决长程目标导航；
- **SoRB**（在线版）：与 ViNG 打平，但需要 **200 小时在线数据**且每个实验都要重新采集，而 ViNG 只需 40 小时离线数据。

### 4.4 Q3：消融实验（Table II）

各控制器变体在不同目标距离下的成功率：

| 控制器 | d=10 | d=20 | d=30 | d=40 | d=50 |
|---|---:|---:|---:|---:|---:|
| Direct Actions (Discrete) | 0.87 | 0.81 | 0.74 | 0.65 | 0.45 |
| Direct Actions | 0.98 | 0.89 | 0.74 | 0.73 | 0.40 |
| Waypoint, Discrete | 1.0 | 0.95 | 0.91 | 0.82 | 0.70 |
| **Waypoint（ViNG）** | 1.0 | 1.0 | 0.95 | 0.88 | 0.81 |
| TD Waypoint | 1.0 | 1.0 | 0.96 | 0.87 | **0.87** |
| Waypoint, No Pruning | 1.0 | 0.88 | 0.81 | 0.79 | 0.52 |
| Waypoint, Only Positives | 1.0 | 0.91 | 0.75 | 0.76 | 0.43 |

三个结论：

1. **途经点作为中层动作空间是关键**：直接回归动作（Direct Actions）在远程目标上崩溃（0.40~0.45 @ 50m），而途经点分层设计保持 0.7+；
2. **监督 vs TD 学习差别不大**：TD Waypoint 与监督版相当（50m 处还略优），论文预期在最短路径远短于随机游走距离的场景 TD 会更重要；
3. **两个关键洞察都不可或缺**：去掉图剪枝（No Pruning）或去掉负样本（Only Positives），50m 处成功率从 0.81 分别掉到 0.52 和 0.43。

### 4.5 真实世界应用

- **无接触末端配送**：在居民区中，用户拍一张投递点照片，ViNG 自主配送邮件和食物；
- **自主巡检**：大学校园等未建图/GPS 受限区域，把巡检点指定为图像，ViNG 周期性巡航，通过对比当前观测与拓扑图中历史观测发现异常。

## 五、局限与影响

### 5.1 局限

- **依赖静态离线数据集**：真实任务的环境是非平稳的（光照变化、动态物体），观测分布随时间漂移；
- **拓扑图是回忆式的**：只能到达"见过的"地方附近，无法推理完全未探索区域；
- 论文将"对分布偏移鲁棒的观测/目标表征"列为未来工作。

### 5.2 影响与谱系

ViNG 是 Berkeley 视觉导航谱系（BADGR → ViNG → GNM → ViNT → NoMaD）中的关键一环：

- 它确立了"**学习的拓扑记忆 + 图搜索 + 目标条件控制器**"这一范式可以在真实机器人上纯离线工作；
- **负样本挖掘**对抗分布偏移、**图剪枝**控制图规模、**途经点分层**连接规划与控制——这三个技巧被后续工作广泛继承；
- GNM 将其推广到多机器人、多环境通用导航模型，ViNT 进一步做成视觉导航基础模型——本仓库另有 GNM 的专门笔记（`gnm_paper.pdf`）。

## 六、总结

ViNG 的核心贡献可以浓缩为一句话：

> **用学习的动力学距离把"见过的画面"组织成可规划的拓扑记忆，再用分层控制器执行图搜索的结果——三个工程洞察（负样本挖掘、图剪枝、途经点分层）让这套范式第一次纯靠离线真实数据在真实机器人上跑通长程视觉导航。**

在当时（2020 年底），它回答了一个被普遍质疑的问题：不建几何地图、不用仿真器、不在线试错，机器人能不能只凭"经验"和一张照片学会认路？ViNG 给出的答案是可以的——40 小时离线数据、40 米以上目标、86% 成功率，以及 60 分钟适配全新环境的自我改进能力。
