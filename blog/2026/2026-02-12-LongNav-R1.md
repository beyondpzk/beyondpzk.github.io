# LongNav-R1：面向长程 VLA 导航的 Horizon-Adaptive 多轮强化学习

> **论文**：*LongNav-R1: Horizon-Adaptive Multi-Turn RL for Long-Horizon VLA Navigation*  
> **作者**：Yue Hu, Avery Xi, Qixin Xiao, Seth Isaacson, Henry X. Liu, Ram Vasudevan, Maani Ghaffari  
> **发布时间**：2026-02-12  
> **arXiv**：https://arxiv.org/abs/2602.12351

---

## 摘要

LongNav-R1 是一个面向长程导航的**端到端多轮强化学习（RL）框架**，专门用于优化视觉-语言-动作（VLA）模型。与现有单轮范式不同，LongNav-R1 将导航决策过程重新表述为 **VLA 策略与具身环境之间的连续多轮对话**。该框架引入 **Horizon-Adaptive Policy Optimization（HAPO）**，在优势估计中显式考虑不同 horizon 长度，实现精确的时间信用分配。LongNav-R1 在四个仿真基准上取得 SOTA，并在真实世界部署中展现鲁棒性。

---

## 一、研究背景与动机

### 1.1 长程导航的挑战

长程导航（long-horizon navigation）面临三个核心挑战：

1. **信用分配困难**：最终成功/失败很难归因到中间某个具体动作；
2. **探索效率低**：长 horizon 中随机探索效率极低；
3. **行为僵化**：基于人类演示的模仿学习容易过拟合到演示分布，缺乏多样性。

### 1.2 核心洞察

LongNav-R1 的核心论点是：

> **导航应该是一个多轮对话过程，而不是单轮决策。** 智能体需要：
> 1. 从历史交互中推理因果关系；
> 2. 预测当前动作对未来多步的影响；
> 3. 在线学习，避免对人类演示的过度依赖。

## 二、方法架构

### 2.1 多轮强化学习框架

```
Episode 开始
    ↓
Turn 1: 观测 → VLA 策略 → 动作 → 环境反馈
    ↓
Turn 2: 新观测 + 历史 → VLA 策略 → 动作 → 环境反馈
    ↓
...
    ↓
Turn N: 任务结束 / 达到最大步数
```

关键区别：
- **单轮范式**：每个决策独立，不考虑长期后果；
- **多轮范式**：整个 episode 是一个连续的决策序列，策略学习考虑历史和未来。

### 2.2 Horizon-Adaptive Policy Optimization (HAPO)

HAPO 是 LongNav-R1 的核心创新，解决长 horizon 中的信用分配问题：

#### 问题

标准 RL 方法（如 PPO、GRPO）在优势估计时通常假设固定 horizon，但导航任务中：
- 有的 episode 很短（几步就完成）；
- 有的 episode 很长（需要几十步）；
- 不同长度 episode 的奖励尺度差异巨大。

#### 解决方案

HAPO 显式考虑 horizon 长度：

1. **Horizon-aware advantage normalization**：根据 episode 长度调整优势估计；
2. **Critic-free advantage estimation**：不依赖额外的价值网络，降低计算开销；
3. **Sequential decision-making**：通过多轮 rollout 学习长期依赖。

### 2.3 在线 Token 剪枝

为了处理长 episode 中的内存瓶颈，LongNav-R1 引入**在线 token 剪枝**：

- 保留完整 KV cache 以维持因果一致性；
- 动态剪枝不重要的历史 token，减少内存占用；
- 未来工作将探索选择性 KV cache 驱逐和空间感知全局记忆。

## 三、实验评估

### 3.1 仿真基准

LongNav-R1 在四个仿真基准上取得 SOTA：

| 基准 | 任务类型 | LongNav-R1 表现 |
|---|---|---|
| 基准 A | 长程 ObjectNav | SOTA |
| 基准 B | 长程 VLN | SOTA |
| 基准 C | 多目标导航 | SOTA |
| 基准 D | 动态环境导航 | SOTA |

### 3.2 真实世界部署

LongNav-R1 在真实机器人上验证，展现：
- **鲁棒性**：对传感器噪声和环境变化具有鲁棒性；
- **泛化性**：无需微调即可在真实环境中工作；
- **长程稳定性**：在长 episode 中保持稳定性能。

### 3.3 在 NavVerse 上的零样本表现

NavVerse 将 LongNav-R1 作为 **VLA-RL 方法**的代表进行评估：

#### ObjNav

| 指标 | LongNav-R1 | 对比 |
|---|---|---|
| All Scenes SR | 4.59% | UniNaVid 11.62% |
| All Scenes SPL | 0.62 | UniNaVid 2.58 |
| Indoor SR | 6.67% | UniNaVid 17.33% |
| Outdoor SR | 2.44% | UniNaVid 4.88% |
| Indoor-to-Outdoor SR | 3.16% | UniNaVid 8.42% |
| Collision Rate | 0.34 | 较高 |
| Avg. Distance to Obstacles | **1.17** | 最高 |
| Coverage Efficiency | 0.50 | 较高 |

#### PlaceNav

| 指标 | LongNav-R1 | 对比 |
|---|---|---|
| All Scenes SR | 6.50% | UniNaVid 11.38% |
| All Scenes SPL | 1.23 | UniNaVid 3.30 |
| Outdoor SR | 8.82% | UniNaVid 17.65% |
| Indoor-to-Outdoor SR | 3.64% | 与 UniNaVid 持平 |
| Collision Rate | 0.20 | 较低 |
| Avg. Distance to Obstacles | **2.21** | 最高 |
| Coverage Efficiency | **0.65** | 最高 |

#### Indoor-to-Outdoor 过渡分析

| 指标 | LongNav-R1 | 说明 |
|---|---|---|
| Indoor-only | 47.37% / 30.91% | 未能走出室内比例 |
| Reach-outside | 52.63% / 69.09% | 到达室外比例 |
| Timeout | **17.0% / 13.9%** | 最低，说明持续探索能力强 |
| Wrong-goal | **74.5% / 72.2%** | 最高，目标 grounding 是主要瓶颈 |

### 3.4 关键发现

1. **持续探索能力强**：LongNav-R1 的 timeout 比例在所有基线中最低，说明其多轮 RL 框架能有效维持长期探索；
2. **目标 grounding 不足**：wrong-goal 比例最高，说明虽然能持续移动，但准确找到目标的能力较弱；
3. **安全性中等**：碰撞率低于 PoliFormer 但高于 SGImagineNav；
4. **零样本成功率偏低**：在 NavVerse 的零样本设置下，LongNav-R1 的成功率明显低于 UniNaVid。

## 四、优势与局限

### 4.1 优势

- **多轮 RL 框架**：将导航视为连续决策过程，更符合真实导航场景；
- **HAPO 信用分配**：有效处理长 horizon 中的时间信用分配问题；
- **持续探索能力**：timeout 比例低，能在长 episode 中保持活跃；
- **真实世界鲁棒性**：在真实机器人上验证有效。

### 4.2 局限

- **零样本成功率低**：在 NavVerse 上成功率明显低于 UniNaVid；
- **目标 grounding 弱**：wrong-goal 比例高，说明语义 grounding 能力不足；
- **计算开销**：多轮 RL 训练计算成本高；
- **内存瓶颈**：长 episode 中 KV cache 占用大，需要在线剪枝。

## 五、与相关工作的关系

| 工作 | 与 LongNav-R1 的关系 |
|---|---|
| **UniNaVid** | LongNav-R1 是 VLA-RL，UniNaVid 是纯 VLA；UniNaVid 在 NavVerse 上成功率更高 |
| **GRPO / PPO** | LongNav-R1 基于 GRPO 改进，引入 HAPO 处理长 horizon |
| **Imitation Learning** | LongNav-R1 用在线 RL 替代模仿学习，避免行为僵化 |
| **NavVerse** | LongNav-R1 是 NavVerse 评估的 VLA-RL 基线，展现持续探索优势 |

---

## 六、结论

LongNav-R1 提出了一个面向长程导航的**多轮强化学习框架**，通过 Horizon-Adaptive Policy Optimization 解决时间信用分配问题。它在持续探索能力上表现突出（最低 timeout 比例），但在零样本目标 grounding 上存在明显不足（最高 wrong-goal 比例）。

LongNav-R1 的启示是：**多轮 RL 是长程导航的有效范式，但需要与更强的语义 grounding 能力结合**，才能在保持探索效率的同时提高任务成功率。
