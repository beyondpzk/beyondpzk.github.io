# EA-Nav：把"身体尺寸"变成导航策略的一等输入

> **论文**：EA-Nav: Learning Safe Visual Navigation Policies with Embodiment Awareness
> **链接**：https://arxiv.org/abs/2607.19880（v1 2026-07-22，v2 2026-07-29）
> **项目主页**：https://ea-nav.github.io
> **录用**：ACM MM 2026（Rio de Janeiro）
> **作者**：Jialu Zhang*, Yong Du*, Xianda Guo*, Shunwang Sun, Xinqi Liu, Yue Sun, Guodong Lu, Wei Sui†, Jituo Li†
> **机构**：浙江大学、武汉大学、湖南大学、D-Robotics（地瓜机器人）

---

## 摘要

EA-Nav 研究的是**跨本体导航（cross-embodiment navigation）**问题：同一个视觉观测，对不同尺寸/形态的智能体意味着不同的正确动作——猫会钻过窄缝，车会绕行。只看图像的策略面对的是一个**一对多的观测-动作映射**，只能学到多个行为模式的"平均"，这是跨本体导航的根本歧义。

现有路线主要靠强化学习（让不同本体在仿真里试错），但探索空间大、收敛不稳、奖励设计重，难以支撑规模化预训练与真实部署；模仿学习（IL）路线的工作很少。EA-Nav 提出了一个 **IL 框架下的本体感知导航方案**，核心是把本体几何参数作为**一等模态**注入模型：

- **预训练**：从互联网第一视角视频构建跨本体导航数据集（约 1000 小时、8 类本体），把本体几何作为条件 token 注入，消除同观测下的动作歧义；
- **微调**：设计"**预测 → 感知 → 纠错**"三段解耦架构，并提出**风险轨迹增强**策略，离线合成专家数据中天然缺失的高风险样本，分别训练空间感知与风险纠错模块，显式利用本体几何实现安全导航。

真机实验（Go2、TurtleBot 物理加宽三档）中，基线方法在最大本体下全部 100% 碰撞，EA-Nav 仍保持 40–60% 成功率。

## 一、问题：为什么纯视觉导航策略无法跨本体

### 1.1 观测-动作的一对多歧义

导航模型的职责是把高层目标转成可执行轨迹。但现有方法几乎只依赖视觉模态，忽略了本体的几何与物理形态。论文用一组 t-SNE 实验把歧义具象化（论文 Figure 5a）：

- **视觉特征**：不同本体的样本在视觉特征空间严重重叠——特征按场景外观组织，而不是按"谁在移动"组织。轮椅和人的样本在视觉空间几乎分不开；
- **运动属性特征**（直行度、速度标准差、启停比、平均加速度、平均转向角变化）：按本体清晰地分成不同的簇。

结论：车、狗、人穿过同一个空间会留下明显不同的轨迹，**只看像素无法判断"期望哪种行为"**，策略只能学到一个平均化的拟合。

### 1.2 现有路线的缺口

| 路线 | 代表 | 问题 |
|---|---|---|
| RL 试错 | The One Ring 等 | 探索空间大、收敛不稳，通常还需要 IL 提供好的初始化 |
| 仿真 IL | X-Nav | 依赖仿真数据，sim-to-real 鸿沟难跨 |
| IL + 几何增强 | **ExAug**（ICRA'23） | 用离散 waypoint + SDF 建立运动-环境关系，无法准确反映连续空间中的轨迹安全；且基于当前时刻反馈调整未来轨迹，决策短视 |

EA-Nav 的定位：**在 IL 框架内解决本体信息建模**，同时支持大规模预训练与真实世界微调。

### 1.3 与扩散策略的区别

面对同一观测的多模态动作，扩散方法（Diffusion Policy、NoMaD 等）选择显式建模动作分布；EA-Nav 走的是另一条路——**用本体几何条件化来消除歧义本身**，让策略学到确定性的、本体特异的动作预测。两种思路并不互斥，但后者显然更省推理成本。

## 二、任务定义与本体参数化

本体几何用一个 4 维向量描述：

```
m = [Lb, Wb, Hb, Pmax]
```

即本体的**长、宽、高、最大可通过高度**（maximum traversable height）。

任务形式化：给定图像序列 `I_{t-k:t}`、当前深度 `D_t`、自我中心目标 `g ∈ R²` 与本体参数 `m`，策略 `π_θ` 预测 **H = 8 步动作序列**，每步动作 `a_t = [v_t, w_t]`（线速度、角速度）。状态定义为 `s_t = {I_{t-k:t}, D_t, g, m}`。实际部署时相对目标 `g` 由机载里程计更新，位姿本身不直接进入策略输入。

标准行为克隆目标是最小化预测动作与标签的 L2 误差。但论文指出：数据集中的本体参数只有有限的离散取值，**单靠 BC 很难学到从几何特征到动作控制的可泛化映射**——这正是解耦架构与风险增强要解决的问题。

## 三、模型架构：预测 → 感知 → 纠错三段解耦

整体流水线是 **prediction → perception → correction**，三个头解耦，使得风险感知与纠错可以在增强出的高风险轨迹上单独训练。

### 3.1 Input Encoder：130 个上下文 token + 单向交叉注意力

- RGB 用 **DINOv3-S**、深度用 **ConvNeXt-T** 提取特征，与目标 token、几何 token 一起投影到共享的 384 维空间，得到 **Nc = 130 个上下文 token**——远多于先前工作的 8–10 个，保留细粒度空间信息；
- 关键设计是**单向交叉注意力**：Action Prediction 的专用 query 可以读上下文特征，但**不能回写**。

为什么要"单向"？因为上下文特征后续还要被感知与纠错模块复用——如果它被某条预测出的高风险轨迹"污染"，下游的风险判断和纠错就会失效。共享表征必须保持干净，只对观测、目标、本体信息负责。

### 3.2 Action Prediction：动作序列 → 显式空间轨迹

把动作 token 解码为 `(v, w)` 序列后，**积分成机器人坐标系下的局部 waypoint 轨迹**，再重新编码为显式的空间轨迹特征 `z_traj`。这个设计给下游两个模块一个"几何抓手"——策略打算往哪儿走，以显式轨迹的形式暴露出来，显著降低了距离预测的难度。

### 3.3 Spatial Perception：逐 waypoint 的最近障碍距离回归

- 输入：`z_context`（已含本体信息）+ `MLP(z_traj)`，经 Transformer 与 MLP 输出每个 waypoint 的最近障碍距离 `d̂ = [d̂₁, ..., d̂_H]`；
- 预测最小距离低于安全阈值 **δs = 0.5 m** 即判定为高风险轨迹；
- 两个重要设计决策：
  1. **该模块的 loss 会回传更新共享上下文特征**。多模块系统中共享特征通常被主任务（动作回归）主导，而距离预测需要更细粒度、更几何感知的特征——不回传就无法收敛；
  2. **与 Action Prediction 顺序串联而非并联**。串联结构使得训练时可以把预测动作**替换成增强出的高风险轨迹**（且增强轨迹被约束在当前视野内，局部场景上下文与原观测一致，共享特征可直接复用）；并联结构则无法这样操纵中间表示。

### 3.4 Risk-Aware Correction：19 bin 的全局偏航角修正

纠错模块只在风险超阈值时触发。一个直觉设计是回归一条修正后的动作序列，但论文指出：纠错模块复用的上下文与动作预测几乎相同，**在同一输出空间做预测只会重复而非补充** Action Prediction 的行为。因此改为预测一个**低维全局偏航偏移**：

- 修正空间离散化为 **19 个 bin，覆盖 [−45°, 45°]，间隔 5°**，模型输出每个 bin 的可行概率 `p_corr ∈ [0,1]^B`；
- 训练用 **multi-hot 监督**（一个高风险状态往往对应多个可行的修正方向——修正是一对多的）；
- 推理时先取可行集 `B̂ = {b | p_corr(b) > τ}`，再选**偏离原轨迹最小的可行 bin**：`Δθ̂ = argmin_{b∈B̂} |b|`。

对短视距（short-horizon）预测设定，整体旋转轨迹已足够完成有效修正；而小本体在开阔空间等场景下多数轨迹本就不需要修正——这正是感知模块先行、纠错按需触发的动机。

## 四、风险轨迹增强：合成专家数据里"不存在"的样本

### 4.1 动机：专家数据天然没有碰撞

真实导航数据由熟练操作者录制，几乎不含碰撞——**恰恰是用来教风险感知与纠错的样本，在专家轨迹中按构造就不存在**。再多演示数据也补不上这个缺口。EA-Nav 的方案是**离线合成**这些缺失样本，推理时完全不需要这部分管线。

### 4.2 三步管线

1. **局部点云地图**：把未来 H 步内的深度观测、轨迹、相机内参融合成机器人中心的局部点云。聚合短视距未来观测可以恢复轨迹周边更完整的几何（仅离线用）；
2. **本体感知的膨胀占据栅格**：用中心视野的有效深度点 **RANSAC 拟合主地平面**，其余视为障碍物，再**按机器人自身尺寸与最大可通过高度膨胀**，得到 embodiment-aware occupancy grid。同一个场景，猫、马、轮式机器人对应的可通行性判定不同；
3. **候选轨迹生成与筛选**：对原始轨迹计算安全系数 `s_d = d_min / max(‖w_H − w_0‖², ε)`（提供朝最近障碍物移动的参考尺度），从样条平滑轨迹出发均匀缩放所有 waypoint（`w̃_i = w_0 + α(w_i − w_0)`，α 在 s_d 附近采样），再叠加 −45°~45°、5° 间隔的旋转，形成候选池。每个候选在膨胀栅格上做碰撞检查：**碰撞的成为风险轨迹**（监督空间感知），**无碰撞的定义可行修正 bin**（提供 multi-hot 监督）。

这样每个高风险样本都天然配对"从该状态出发可行的恢复方向"，从有限的微调数据中放大出大规模监督。

## 五、数据：1000 小时、8 类本体的互联网视频预训练集

### 5.1 预训练数据构建

- 从互联网收集约 **1000 小时**真实第一视角视频，覆盖 **8 类本体**：人、猫、狗、马、自行车、卡丁车、汽车等（图 1 还展示了轮椅等类别），按类别人工标注本体几何；
- 用 **Depth-Anything-3** 自动标注深度、轨迹与相机内参（伪标签）。关键洞察：**导航预训练只要求轨迹与观测之间的尺度一致性，不要求精确的度量对齐**——这使网络视频可用；
- 按轨迹平滑度过滤噪声样本；另混入 HM3D mini 补充室内覆盖。

### 5.2 与现有导航数据集对比

| 数据集 | 本体数 | 时长(h) | 来源 | 监督 | 相机 |
|---|---|---|---|---|---|
| SCAND | 2 | 9 | 真实 | GT | 针孔 |
| TartanGround | 3 | ~40 | 合成 | GT | 针孔 |
| LeLaN | 2 | 129 | 真实 | 伪标签 | 鱼眼 |
| CityWalker | 2 | 2000 | 真实 | 伪标签 | 针孔 |

时长不是最大，但**本体覆盖是真实第一视角导航数据集中最广的**——这正是本文的核心诉求。

### 5.3 训练流程

- **预训练**：互联网视频噪声大、无法提供可靠几何监督，只用 BC 优化动作预测分支；
- **微调**：用 GND、SCAND-Spot、SiT 真实数据 + 风险轨迹增强。动作分支由真实动作 BC 监督，空间感知由占据栅格目标监督，纠错由可行 bin 监督，三者加权联合优化。微调用的深度观测以真实数据的度量尺度轨迹与内参为条件重建，保证物理一致性。

## 六、实验

### 6.1 预训练中的本体消融

去掉几何 token、其余设置不变做对照：加入本体几何后**训练损失、验证损失、测试成功率一致改善**，且验证损失差距**到训练结束都不收敛闭合**——说明收益来自"监督信号变得良定义"（歧义被条件化消除），而非记忆或优化加速。值得注意的诚实观察：去掉几何后性能并不会崩塌，因为图像序列本身隐含部分本体信息（相邻帧像素变化反映速度量级，视点高度与本体尺寸相关）——但显式建模仍然稳定有益，对不输入时序图像的模型尤其重要。

### 6.2 空间感知：风险识别提升约 5 倍

在 i2Nav 数据集上用 5 种本体半径（0.5/1.0/1.5/2.0/2.5 m；Body-L=2.5 m **超出训练范围**，测泛化）评测。高风险阈值 0.5 m，TPR\* 只统计碰撞样本（距离 < 0 m）：

| 设置 | TPR↑ | TPR\*↑ | FAR↓ | MAE(m)↓ |
|---|---|---|---|---|
| w/ 增强（Body-S~Body-L） | 70.6–84.9 | 83.5–95.1 | 0.0–5.3 | 0.471–0.582 |
| w/o 增强 | 8.8–29.2 | 10.0–35.8 | 0.0–1.06 | 0.664–0.799 |

增强把高风险/碰撞样本识别能力提升约 **5 倍**，且几乎不增加误报——"该谨慎的地方谨慎，而不是处处谨慎"。定性结果显示：同一条缝隙对 Body-S 可通过、对 Body-M 勉强、对未见过的 Body-L 判定为不可通行并标红对应 waypoint——**风险是从"场景 × 身体"联合读出的，而非场景 alone**。

### 6.3 轨迹纠错：小角度、可控的修正

同样在 i2Nav 上评测（CSR=修正成功率，MDA=平均修正角，IoU_bin=可行 bin 的 micro IoU）：

| 本体 | CSR(%)↑ | MDA(°)↓ | IoU_bin(%)↑ | 随机策略 CSR | 随机策略 MDA |
|---|---|---|---|---|---|
| Body-S | 57.00 | 12.30 | 70.97 | 66.21 | 22.01 |
| Body-M | 57.19 | 13.00 | 59.30 | 42.36 | 23.20 |
| Body-L | 65.97 | 18.29 | 53.08 | 39.83 | 22.59 |

论文对结果的解读很坦诚：小本体下随机策略 CSR 反而更高，因为可行域大、乱转也容易成功，但代价是修正角度大、不可控；本体越大、可行域越小，随机策略迅速退化，而 EA-Nav 保持稳定且修正角始终较小。IoU_bin 与 CSR 不完全一致（小本体下高 IoU_bin 低 CSR）的原因也被明确解释：远距障碍下可行区间宽，给多个角度打高分即可获得高区间重叠，但不代表能找准真正有效的修正角。

### 6.4 仿真导航：InternUtopia + NavDP 资产

三个难度递增的场景（Scene1 easy / Scene2 hard / Scene3 indoor）：

| 方法 | S1 SR/SPL | S2 SR/SPL | S3 SR/SPL |
|---|---|---|---|
| iPlanner | 0.66/0.54 | 0.50/0.39 | 0.30/0.18 |
| NavDP | **0.73**/**0.63** | 0.60/**0.52** | 0.56/0.41 |
| NoMaD* | 0.55/0.39 | 0.44/0.31 | 0.36/0.22 |
| ExAug* | 0.61/0.42 | 0.46/0.33 | 0.38/0.24 |
| Ours (w/o corr) | 0.62/0.51 | 0.45/0.35 | 0.43/0.31 |
| **Ours (w/ corr)** | 0.70/0.59 | **0.62**/0.51 | **0.60**/**0.49** |

两个诚实的观察：基础模型（w/o corr）低于 NavDP，原因是训练数据以真实环境为主、规模与多样性不及 NavDP 的大规模合成数据，存在 sim 分布差；加入感知+纠错后平均提升约 **31%**，且在更杂乱的 Scene2/3 增益最大——本体条件与任务归纳偏置有效补偿了数据规模劣势。

### 6.5 真机实验：视觉观测不变，只改身体

实验设计是全文最漂亮的一笔：**不换机器人，而是给同一台机器人物理加宽**——在 Go2 四足与 TurtleBot 两侧安装刚性挡板，分 Body → Body+ → Body++ 三档。**相机与安装位置不动，视觉观测在三档间完全一致，唯一变化的是本体向量 m**——行为差异可以干净地归因于几何条件而非视觉域偏移。

定性结果：同一观测下，Body 档直接穿窄缝，Body+/Body++ 切换为开阔绕行路线，且路线外弯程度与本体尺寸成比例；基线只看图像，三档都往缝里扎。定量（每方法每设置 5 次试验）：

| 机器人 | 方法 | Body SR/CR | Body+ SR/CR | Body++ SR/CR |
|---|---|---|---|---|
| Go2 | iPlanner | 0.20/1.00 | 0.20/1.00 | 0.00/1.00 |
| | NavDP | 0.60/0.60 | 0.40/0.80 | 0.00/1.00 |
| | NoMaD* | 0.20/0.20 | 0.00/0.40 | 0.00/1.00 |
| | ExAug* | 0.20/0.20 | 0.20/0.40 | 0.00/1.00 |
| | **Ours** | **0.80**/0.20 | **0.60**/0.20 | **0.60**/**0.00** |
| TurtleBot | iPlanner | 0.60/0.40 | 0.40/0.80 | 0.00/1.00 |
| | NavDP | 0.80/0.00 | 0.60/0.60 | 0.00/1.00 |
| | NoMaD* | 0.20/0.20 | 0.00/0.60 | 0.00/0.60 |
| | ExAug* | 0.20/0.20 | 0.20/0.60 | 0.00/0.20 |
| | **Ours** | 0.60/0.20 | **0.60**/0.40 | **0.40**/0.20 |

**Body++ 下所有基线碰撞率 100%**（NoMaD 在 TurtleBot Body++ 的 CR 0.20 是 SR 全为 0 下的"不敢动"式低碰撞），EA-Nav 仍保持可用成功率。论文还指出：点目标方法因激进的目标导向行为碰撞率普遍偏高；图像目标方法更安全但在低纹理环境退化明显。

## 七、分析与评价

### 7.1 核心贡献：把"身体"从下游规划器的事后约束变成策略的输入

传统做法把本体尺寸留给下游规划/控制层处理（代价地图膨胀、footprint 检查），导航策略本身对本体格无动于衷。EA-Nav 把几何向量提升到策略输入端，配合"互联网视频 + 伪标签"的数据路线，**让本体意识在预训练阶段就被习得**，而不是部署时再补丁。这与本仓库此前记录的 ExAug 思路一脉相承，但在"连续空间整体修正 vs 离散 waypoint 调整"、"预训练条件化 vs 仅微调增强"两点上都往前走了一步。

### 7.2 方法层面的亮点

- **单向交叉注意力**保持共享上下文干净——多模块系统中"表征被主任务绑架"是常见暗坑，这里用结构约束直接规避；
- **修正输出空间的设计**（全局偏航 bin 而非动作序列增量）体现了对"模块间互补而非重复"的清晰思考；multi-hot + 最小偏移选择优雅地处理了一对多恢复与"能不绕就不绕"的偏好；
- **风险轨迹增强**抓住了模仿学习的结构性盲区（专家数据无失败样本），且全离线、零推理成本；
- 消融与失败模式讨论异常诚实（随机基线 CSR 更高、IoU_bin 与 CSR 的背离、基础模型不如 NavDP），在导航论文里不多见。

### 7.3 局限与观察点

- **本体建模只有几何、没有运动学**：论文自己承认 m 不含转弯半径、加速度约束等 kinodynamic 因素——运动模式与训练分布差异大的本体（如 Ackermann 转向的车 vs 全向轮），即使几何相似也部署受限。这恰是真机实验"物理加宽同一机器人"设计无法覆盖的维度；
- **修正只有偏航**：全局旋转对短视距足够，但面对需要平移/后退才能脱困的场景（死胡同、贴墙），单一 yaw 修正的表达力有限；
- **深度依赖伪标签**：预训练靠 Depth-Anything-3 的尺度一致性假设，极端场景（玻璃、水面、动态物体占比高）下的伪标签质量会传导到占据栅格与风险标签；
- **真机规模小**：每设置仅 5 次试验，场景为受控布置；8 类预训练本体与部署本体（狗形/轮式）之间的迁移路径也没有直接消融；
- **关注点**：代码/数据是否开源（主页暂未放出链接）、kinodynamic 属性的建模方式、以及与 VLA 导航主线（OmniVLA、NavDP 系）的融合可能。

## 八、总结

EA-Nav 一句话概括：

> **在模仿学习框架内，用 4 维本体几何向量做条件化：预训练阶段靠 1000 小时、8 类本体的互联网视频 + 几何 token 消除"同观测、异动作"的歧义；微调阶段靠"预测→感知→纠错"解耦架构与离线风险轨迹增强，让策略按身体尺寸读出风险、按需小角度绕行——在视觉观测完全不变、只把机器人物理加宽的对照实验里，基线全军覆没而 EA-Nav 仍然可用。**

它对 VLN/导航领域的启示大于单个模型：**"谁在导航"是和"看见什么"同等重要的输入模态**，而专家数据的失败样本缺失必须用合成增强补齐。对做跨本体策略和导航数据工程的人，这两点都值得直接借鉴。
