# TairosAgent：腾讯的具身原生智能体框架

> **产品**：TairosAgent（钛螺丝智能体框架）
> **发布方**：腾讯 Robotics X 实验室 + 福田实验室（基于腾讯混元大模型）
> **发布时间**：2026-07-18（WAIC 2026 腾讯 AI 应用创新论坛）
> **所属平台**：Tairos「钛螺丝」具身智能开放平台（2025-07-27 首发）
> **官网**：https://tairos.tencent.com/tairosAgent

---

## 摘要

TairosAgent 是腾讯 Tairos「钛螺丝」具身智能开放平台中的**智能体框架层**，定位是"面向真实物理世界的具身原生智能体框架"。它模拟人类"**本能反应 — 思考决策 — 经验沉淀**"的三级认知架构，配合对环境、本体、任务的持续记忆，让机器人能够实时感知、自主规划并主动行动。

在腾讯的具身技术体系中，TairosAgent 扮演**调度整合者**的角色：把三个具身基座模型（Hy-Embodied-VLM "右脑"、Hy-Embodied-RxBrain "大脑"、Hy-Embodied-VLA "小脑"）与各家机器人本体整合成"持续感知、持续决策、持续行动"的完整闭环。工程上通过 **HAL 硬件抽象层**适配多形态本体（宇树 G1、智元灵犀 X2、乐聚夸父 5、众擎 PM01、越疆机器狗等），通过 **Skill Hub** 提供即插即用的业务技能生态。目前已在导游导览场景完成验证落地（敦煌莫高窟数字展示中心等）。

---

## 一、背景：Tairos 平台的来龙去脉

### 1.1 2025-07-27：Tairos 首发

在 WAIC 2025 上，腾讯 Robotics X 实验室与福田实验室联合发布 **Tairos「钛螺丝」**——号称**国内首个以模块化方式提供大模型、开发工具和数据服务的具身智能软件平台**，以即插即用方式向机器人行业开放。

腾讯首席科学家、Robotics X 与福田实验室主任**张正友**给出了动机判断：

> 当前的通用大模型如同"**缸中之脑**"——擅长文本推理、知识问答，却缺乏与物理世界持续交互反馈的闭环：未必真正理解物体的位置、空间关系与可操作性，也难以在持续变化的环境中边行动、边接收反馈、边及时调整。

平台的初始组成是"**模型算法 + 云服务**"两大块：

| 组成 | 内容 |
|---|---|
| 规划大模型 | 复杂推理、自我演进、外部工具调用 |
| 多模态感知模型 | 语言-视觉-空间联合理解，层次化信息与具身记忆 |
| 感知行动联合大模型 | 零样本泛化、小样本快速适配，跨本体稳定操作、多地形稳定运动 |
| 云服务 | 仿真平台（基于 Isaac Sim 的云端仿真）、数据服务、开发工具 |

平台的使命是"为机器人本体与应用开发商补齐关键软件能力"——就像给各类机器人装上"大脑"，让机器人从被动执行的机械体进化为主动适应的智能体。

### 1.2 2026-07-18：全面升级，发布 TairosAgent

一年后的 WAIC 2026，腾讯集中发布全套具身智能成果，**首次系统性打通"感知—身体—行动"完整闭环**：

| 组件 | 角色 | 作用 |
|---|---|---|
| **Hy-Embodied-VLM-1.0** | "右脑" | 理解图像、空间和场景（本仓库另有专门笔记） |
| **Hy-Embodied-RxBrain-1.0** | "大脑" | 统一认知、规划、对未来状态的想象 |
| **Hy-Embodied-VLA-0.5** | "小脑" | 把高层目标转化为连续、可纠错的动作 |
| **Apexio** | 具身智能体 | 面向具体机器人的智能体产品 |
| **TairosAgent** | **智能体框架** | **把"左右脑/大脑/小脑"和身体调度整合成完整系统** |

张正友在论坛上进一步阐述："语言并不等于全部认知，它只是智能向外表达的一个通道。"真正的智能需要让语言、视觉、空间认知、身体控制和环境反馈连通起来，在"感知—身体—行动"的闭环里接受验证。这五项成果体现的正是"**从离身走向具身、从分裂的模块走向整体的闭环**"的基本思路。

## 二、TairosAgent 框架详解

### 2.1 定位：具身原生智能体框架

TairosAgent 不是某个具体模型，而是**让模型们在真实机器人上协同工作的运行时框架**（agent runtime）。官方定义：

> 一套面向真实物理世界的具身原生智能体框架。通过模拟人类"本能反应—思考决策—经验沉淀"的三级认知架构，并配合对环境、本体、任务的持续记忆，让机器人能够实时感知、自主规划并主动行动——把大模型的智能真正落到机器人的双手与双脚上。

### 2.2 三级认知架构

| 层级 | 人类类比 | 功能 | 对应系统组件 |
|---|---|---|---|
| **L1 本能反应** | 脊髓反射 | 即时感知与快速反应 | 感知模型 + VLA（高频） |
| **L2 思考决策** | 大脑皮层 | 任务规划与决策 | RxBrain 规划模型（事件触发） |
| **L3 经验沉淀** | 长期记忆 | 经验积累与复用 | 持续记忆系统 |

这种**快慢系统分层**与业界主流架构在思想上高度一致——对比 ABot-N0 的"安全层（<50ms）→ Neural Controller（10Hz）→ VLA（2Hz）→ Agentic Planner（事件触发）"，同样是反应层快、规划层慢、记忆层沉淀的分工。

### 2.3 持续记忆：环境、本体、任务

TairosAgent 强调对三类对象的**持续记忆**：

- **环境记忆**：构建层次化空间信息（由多模态感知模型支撑的三维层级地图）；
- **本体记忆**：机器人自身状态与能力的建模；
- **任务记忆**：历史任务的执行经验，支撑"经验沉淀"层级。

这与 ABot-N0 的 Topo-Memory（Block/Road/Function/Object 四层）和 VL-Nav 的"3D 场景图 + 图像记忆"属于同一设计范式——**用外部记忆锚定大模型的规划**，只是 TairosAgent 把本体状态也显式纳入了记忆对象。

## 三、工程体系：HAL + Skill Hub

### 3.1 HAL 硬件抽象层与已适配本体

TairosAgent 通过**硬件抽象层（HAL）**屏蔽不同机器人本体的差异——这是其"平台"属性的核心：本体厂商不需要自己造大脑，应用开发者不需要关心底层硬件。完成 HAL 适配的机型即具备运行 Skill Hub 应用的底层能力：

| 本体 | 形态 | 已适配技能 |
|---|---|---|
| 宇树 G1 | 人形 | 全部 6 个技能（含独有的"坐椅子与起身"） |
| 智元灵犀 X2 | 人形 | 主动迎宾、语音播报 |
| 乐聚夸父 5 | 人形 | 运动控制、全流程导览、路线管理 |
| 众擎 PM01 | 人形 | 语音播报、运动控制、全流程导览、路线管理 |
| 越疆机器狗 | 四足 | 主动迎宾、语音播报、运动控制 |

### 3.2 Skill Hub：即插即用的技能生态

高层业务功能被封装为 **Skill**，跨多形态设备"一键拷贝、即插即用"。当前技能库明显面向**导览/接待**场景：

| Skill | 功能 | 说明 |
|---|---|---|
| **主动迎宾** | 自主识人打招呼 | 人脸检测触发，自动播报欢迎语 + 挥手/鼓掌，可配置冷却时间；面向展厅、门店前台整日待机 |
| **语音播报** | TTS 文本转语音 | 最基础的表达原子能力，被迎宾、导览等上层技能广泛复用 |
| **运动控制** | 移动 + 手势 | 移动带避障、转向可设角速度；握手、拥抱、鼓掌、挥手、比心等十余种拟人手势 |
| **坐椅子与起身** | 拟人化坐站闭环 | "看见椅子—走过去—坐下—再起身"，含视觉识别、定位导航、拟人动作（仅 G1） |
| **全流程导览讲解** | 按路线带客参观 | 三种模式：default 自动导览、lead 前导带客、follow 跟随用户；举手手势 + 人脸锁定用户防跟错；支持暂停与跳转 |
| **导览场景与路线管理** | 路线数据管理 | 场景/点位/路线/动作全生命周期管理，按点位自动填充讲解词、配置手势 |

Skill 之间是**组合复用**关系：语音播报、运动控制是原子能力，主动迎宾、全流程导览是组合技能——这套"原子技能 → 组合技能 → 场景应用"的分层，正是 Agent 工程中 Skill 抽象的标准做法。

## 四、落地与生态

### 4.1 已验证场景

- **敦煌莫高窟数字展示中心导览**：Robotics X 与宇树科技协同打造的机器人导览方案（本体：宇树 G1），已试点运营；
- **深业上城众擎机器人零售旗舰店**："AI 机器人+"理念落地，整合众擎、京东之家、徕芬、影石、拓竹等多方资源（本体：众擎 PM01）；
- 官方口径：已在**导游导览**等真实场景完成验证落地，并通过软硬一体的快速适配能力支撑多形态机器人规模化应用。

### 4.2 云端仿真环境

- 基于 **Isaac Sim** 的云端仿真，免配置一键直达；
- 支持实时验证 Tairos 三个大模型在仿真中的运行效果；
- 内置 **62 类通用物体仿真 + 20 种平滑交互动画**，支持自定义机器人导入与智能体导航交互。

### 4.3 RoboFusion 开源

平台还开源了 **RoboFusion** 本体互连技术——"一线到底，融合通信"，构建从总线物理接口到通信协议的全栈互连体系，解决传统机器人布线复杂、扩展困难、实时性不足的痛点，为"软件定义机器人"提供底层基础。

## 五、分析与评价

### 5.1 路线定位：模块化平台 vs 端到端 VLA

腾讯走的是**模块化平台路线**，与端到端学习路线形成鲜明对照：

| 维度 | TairosAgent（模块化平台） | 端到端 VLA（ABot-N0 等） |
|---|---|---|
| 智能来源 | 多个专精模型分工（感知/规划/行动） | 单一模型统一感知-推理-动作 |
| 数据需求 | 低（模型各自预训练，平台零样本组合） | 高（千万级轨迹数据引擎） |
| 可解释性 | 高（每层输出可查） | 低 |
| 适配新本体 | HAL 抽象层快速适配 | 需重新微调/采集数据 |
| 能力上限 | 受各模块能力约束 | 随数据规模上升 |
| 当前主打场景 | 导览接待（窄但落地） | 通用导航（广但 demo 居多） |

值得注意：这条路线与 VL-Nav 的神经符号系统、以及"云端 Planner + 边缘执行"的主流工程方案同属一个阵营——**把大模型当调度器而非全身**。

### 5.2 生态打法：做机器人行业的"安卓"

Tairos 的战略意图很清晰：

- **不造本体**——本体交给宇树、智元、乐聚、众擎、越疆等合作伙伴；
- **不独占应用**——Skill Hub 让应用可跨机型拷贝；
- **做中间层**——模型（脑）+ 框架（TairosAgent）+ 工具（仿真/数据）+ 互连（RoboFusion），卡住"大脑供应商"的生态位。

这与 ABot 依托高德地图生态、华为/英伟达依托算力生态的打法类似：大厂都在用自己最擅长的资产切入具身智能。

### 5.3 局限与观察点

- **场景集中**：Skill 库与落地案例清一色导览接待，离通用任务尚远——导览是"低动态、低操作复杂度"的友好场景；
- **技术细节未公开**：三级认知架构、记忆系统目前只有概念性描述，无论文或技术报告，无法评估实现深度；
- **"具身原生"成色待验证**：宣传口径强调闭环与原生智能，但从 Skill 构成看，当前能力仍以**导航 + TTS + 手势编排**为主，精细操作（manipulation）尚未出现在技能库中；
- **关注点**：RxBrain-1.0 与 VLA-0.5 的后续开放程度、Skill Hub 是否出现操作类技能、以及导览之外的首个新场景。

## 六、总结

TairosAgent 可以一句话概括：

> **腾讯具身智能体系的"操作系统层"——上接混元系的三个具身基座模型（右脑/大脑/小脑），下通过 HAL 接各家机器人本体，用三级认知架构跑通"感知—决策—行动—沉淀"闭环，用 Skill Hub 承载应用场景，当前主打导览接待。**

它的意义不在于某个单点技术突破，而在于**工程化整合**：把"缸中之脑"变成"具身闭环"所需要的调度框架、硬件抽象、技能生态和仿真工具打包成平台。对于机器人行业，这是大厂平台化打法的典型样本；对于研究者，它再次印证了"快慢分层 + 外部记忆 + 技能编排"已成为具身 Agent 系统的行业共识架构。
