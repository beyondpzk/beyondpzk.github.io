# Athena-Brain-8B：小鹏的端侧机器人"大脑"模型

> **论文**：Athena-Brain Technical Report — An Efficient Robot Brain for General Intelligence and Embodied Interaction
> **链接**：https://arxiv.org/abs/2607.18985（2026-07-21 提交）
> **作者**：Jialian Li, Junhong Liu, Yuchen Cao, Weiran Guo, Jiaming Song, Xutao Wang, Yi Zhao, Jiangpin Liu, Jie Chen（通讯）
> **机构**：论文首页未标注机构，通讯作者邮箱为 `xiaopeng.com` 域名（小鹏），且评测基于同一团队的 DeepInsight 平台（arXiv:2606.17574）
> **基座**：Qwen3-8B-Base

---

## 摘要

Athena-Brain-8B 是一个 8B 规模的纯语言模型，定位是**机器人的端侧"大脑"（on-device brain）**：不负责感知像素、不输出电机指令，而是在结构化观测与可执行工具（tool）的接口之上，承担高层理解、推理、规划与决策。它要同时满足三个通常互相冲突的目标：

1. **通用智能不丢**——数学、代码、推理、指令遵循、函数调用维持 8B 第一梯队；
2. **具身交互要强**——在闭环文本交互环境中完成长程任务；
3. **生成必须短**——机器人交互是高频决策，冗长的思维链直接转化为延迟。

实现手段是一条**四阶段后训练流水线**：通用 SFT → 通用 RL → 具身专家训练 → 模型合并（Model Merge）。最终在通用 benchmark 上与 Qwen3-8B-Thinking 打平甚至略优、回复却短得多；在自建具身 benchmark 上以 58.52% 的综合成功率碾压所有同规模开源模型（第二名 14%），并超过 Qwen3-Max、Kimi K2.6、DeepSeek-V4-Pro 等零样本参评的前沿大模型，仅次于 GPT-5.5 和 Gemini-3.1-Pro。

## 一、动机：机器人大脑的三个矛盾

论文对现状的判断很清晰，两条现有路线都有缺口：

- **具身基座模型**（如 MiMo-Embodied、RynnBrain）：专注特定环境的行为学习，通用高层推理与规划能力弱；
- **前沿通用 LLM**：推理强但没有为具身交互做过后训练，且 thinking 模式的冗长输出在"感知—推理—动作"高频循环中会累积成不可接受的延迟。

一个实用的机器人大脑必须**把通用智能、具身交互、生成效率放进同一个紧凑模型**——8B 是为了端侧部署。值得注意的是，论文全程用**生成长度**而非实测延迟作为效率指标（硬件无关的代理指标），这个选择诚实且合理。

## 二、训练流水线：四阶段递进

核心思想是**不联合优化所有目标**，而是把能力拆成四个顺序阶段，每个阶段聚焦一个侧面，并自然成为下一阶段的基础。

### 2.1 阶段一：通用 SFT（两阶段递进）

从 Qwen3-8B-Base 出发做监督微调，分两阶段：

- **Stage 1（广度）**：约 558 万加权样本的大规模指令语料，覆盖数学（47.57%）、通用（20.97%）、代码（18.16%）、工具使用（5.64%）、科学（5.27%）、中文问答（2.40%），建立均衡的通用专家；
- **Stage 2（质量）**：规模小得多但精选的高质量语料，侧重回复质量、推理一致性与指令遵循，并显式加入 agent 交互数据为后续工具化训练铺垫。

### 2.2 阶段二：通用 RL——能力变强，回复变短

在 SFT 基础上用 **GRPO** 做大规模 RL，奖励是两项的组合：

- **正确性奖励**：数学、科学、代码等可自动验证任务；
- **token 预算奖励**：显式奖励"用更少 token 答对"，鼓励简洁推理。

关键超参是 **16K 的最大生成预算**。消融显示：4K 预算会明显损害复杂推理任务的表现（综合分 55.57 vs 16K 的 57.36），预算太大则 token 预算奖励失效。训练动态很漂亮——奖励持续上升的同时，平均生成长度稳步下降，即"能力变强、话变少"同时发生。

### 2.3 阶段三：具身专家训练——在可执行环境里闭环学习

这是全文最有特色的部分。**不用静态指令-回复数据，而是让模型在可执行的文本交互环境中闭环训练**：

- **两个环境**：Museum（博物馆导览：导航、访客协助、人机交互）与 Supermarket（超市购物：物体 grounding、移动操作、任务规划），代表公共服务与家庭服务两个互补场景；
- **统一交互协议**：每一步模型接收完整历史（任务、观测、动作、环境反馈、可用工具接口），输出一个结构化 JSON tool call，环境执行后返回新观测；
- **渐进具身等级（E0–E3）课程**：E0 只有区域级拓扑（选相邻区域）；E1 有局部拓扑与朝向；E2 给出四方向物体与粗略距离；E3 则是自我中心的视锥观测（转向决定看见什么）。从被动感知到长程执行逐级加码；
- **训练流程**：先在采集的交互轨迹上做 **4K 步监督 warm-up**，再用 GRPO 做 RL，奖励来自可执行环境评分（Museum 奖励到访进度与完成度，Supermarket 奖励购物车正确性与结账成功），单局上限 100 步。

**具身 RL 的消融**（Table 12/13/14）给出了几条可迁移的工程经验：

| 设计轴 | 结论 |
|---|---|
| 截断规则 | **format-only-stop 显著优于 all-error-stop**：格式错误才终止 rollout，工具执行失败允许恢复——保留"错误恢复轨迹"对最终策略质量是决定性收益 |
| 奖励尺度 | **温和奖励优于惩罚性奖励**：过大的工具错误惩罚（-10）会让 RL 过度优化"避免犯错"而非"推进任务" |
| 地图采样 | 简单地图子集（partial）反而比全量地图训得好：过难/高方差的环境会稀释学习信号，课程难度要适中 |

最优组合（partial maps + mild reward + format-only-stop）把综合分从 pre-RL 的 0.5145 提到 0.6000。

### 2.4 阶段四：模型合并——谱系感知的两阶段 Merge

前述阶段产出多个互补的专家 checkpoint，论文没有做联合训练，而是**在参数空间合并**，且合并算子的选择有明确的几何依据：

- **第一阶段**：同谱系（都以 Athena-SFT 为初始化）的各领域 RL 专家，相对 SFT 锚点定义任务向量，用 **TIES** 合并——同源的逐坐标符号一致性是可解释的，TIES 能有效抑制冲突更新；
- **第二阶段**：一个**不同谱系**的 SFT checkpoint，只用**低权重线性插值**引入。原因是它的位移混杂了谱系级差异与任务差异，量级远大于同源 RL 更新，硬塞进 TIES 投票池会导致严重性能退化（论文实测验证）。

这背后的理论观察与 "RLVR provably learns off the principals" 一致：RLVR 倾向于在主谱之外的低曲率方向更新、保持奇异谱结构，而 SFT 会引起更强的主谱变化——所以"同源 RL 专家可以投票合并，异源 SFT 只能保守插值"。Table 11 显示合并后的模型在多数 benchmark 上追平甚至超过最优单专家（如 AIME 2024 76.67 vs 专家 73.75），具身性能保留了专家的 97% 以上（58.52 vs 60.11），而 ALFWorld 泛化反而超过具身专家（49/134 vs 47/134）。

## 三、实验结果

### 3.1 通用能力：8B 第一梯队，且更省 token

评测覆盖数学（AIME/OlympiadBench 等）、代码推理（LiveCodeBench/ZebraLogic）、通用任务（GPQA/IFEval/MMLU-Redux 等）与函数调用（BFCL/τ²-Bench），统一 thinking 模式、40,960 最大生成长度：

| 模型 | 数学 | 代码推理 | 通用任务 | 函数调用 | 总平均 |
|---|---|---|---|---|---|
| **Athena-Brain-8B** | **69.55** | 63.25 | **58.60** | 56.47 | **60.85** |
| Athena-SFT | 65.91 | 58.64 | 55.83 | 56.81 | 58.56 |
| Qwen3-8B (thinking) | 66.12 | **63.90** | 56.58 | 46.96 | 56.70 |
| MiMo-Embodied-7B | 52.11 | 45.56 | 50.61 | 32.53 | 44.73 |
| MiniCPM4.1-8B | 57.49 | 48.61 | 44.69 | 17.47 | 39.67 |
| RynnBrain-8B | 6.08 | 17.31 | 38.53 | 35.65 | 27.99 |

相比同一基座的 Qwen3-8B-Thinking，总分高出 4 个点以上，且每个"得分点"消耗的 token 显著更少（Figure 8 的 tokens-per-score-point 指标）。RL 阶段相对 SFT 的提升主要集中在数学与代码，知识密集型任务无退化。

### 3.2 具身交互：同规模断层领先，越过多个前沿大模型

在自建 Museum（100 实例）与 Supermarket（120 实例）环境上按 E0–E3 四级评测成功率，外部模型均为**零样本**参评：

| 模型 | 综合成功率 |
|---|---|
| GPT-5.5 | 79.6 |
| Gemini-3.1-Pro | 71.1 |
| **Athena-Brain-8B** | **58.52** |
| Qwen3.7-Max | 54.1 |
| DeepSeek-V4-Pro | 53.3 |
| Kimi K2.6 | 52.4 |
| Qwen3-Max | 43.3 |
| Qwen3-8B-Thinking | 14.0 |
| Athena-SFT | 6.98 |
| RynnBrain-8B / MiMo-Embodied-7B / MiniCPM4.1-8B | 4.13 / 3.71 / 0.32 |

效率维度更夸张：Athena 每次交互平均只生成 **24.25 token**（token cost 0.41），而 Qwen3-8B-Thinking 是 515.38 token（cost 36.81）——成绩只有 Athena 的 1/4，话却是 21 倍。论文的结论：**对紧凑具身模型，提升推理效率比拉长思维链更有价值。**

**OOD 泛化**（零样本 ALFWorld，未参与训练）：36.57% vs Athena-SFT 的 11.94%，提升 3 倍，说明学到的是可迁移的交互策略而非环境记忆；不过仍低于 MiniCPM4.1-8B 的 40.30%，绝对水平还有空间。

**中间探针**（从成功轨迹中采样中间状态构造的细粒度测试）：State-Goal（完成近未来目标）从 6.0% 飙到 59.3%，是收益的主要来源；State-Return（返回先前到访位置）43.8%，虽在开源 8B 中最强一档（41+ 轮后仍保持 32.4%，为同规模最佳），但相对 GPT-5.5（83.0）/Gemini（88.0）差距明显——**长程空间记忆与自定位仍是核心瓶颈**。

### 3.3 案例：错误恢复与功能 grounding

两个典型案例值得一提。博物馆场景中，模型 checkin 失败后没有死循环重试，而是推断"当前位置不对"，主动补一段导航精化位置后完成打卡——用环境反馈修正空间假设。超市场景中，用户需求是功能描述（"溶解马桶污渍的清洁剂 + 刷马桶内壁的刷子"），模型先推理出具体商品、规划跨楼层购物策略，68 步检查 8 个货架后完成结账。

## 四、分析与评价

### 4.1 定位判断：这是"大脑皮层"，不是"全身"

Athena 明确选择了**模块化架构中的认知层**：输入是结构化观测（文本），输出是工具调用，不碰原始传感器和电机。这与本仓库之前记录的 [TairosAgent](2026-07-18-tairosagent.md) 的分层思想（RxBrain 做规划、VLM 做感知、VLA 做执行）完全一致——**LLM 当大脑，感知与低层控制交给专门模块**。对车厂出身的小鹏来说，这个选择很务实：纯文本具身环境是低成本、可程序化验证的训练场，先在"脑"上把闭环决策练出来，再接感知与本体。

### 4.2 真正的贡献在方法论而非刷分

- **"token 预算奖励 + 16K 预算"的组合**给出了能力-效率权衡的可复用配方，对一切高频决策的 agent（不止机器人）都有参考价值；
- **谱系感知合并**把"TIES 该在什么时候用"从经验变成了有几何依据的判据：同源 RL 任务向量可投票，异源大位移只能保守插值；
- **具身 RL 消融**（错误可恢复 > 严苛惩罚、适中难度 > 全量难度）是少见的闭环交互 RL 工程结论，对做 agentic RL 的人直接可用。

### 4.3 需要泼的冷水

- **In-domain 胜利成色要打折**：Museum/Supermarket 是 Athena 的训练环境，前沿大模型是零样本陪跑——"8B 超过 GPT-5.5 以外的所有模型"本质是"训练过 vs 没训练过"的对比，真正无水分的证据是 ALFWorld OOD（36.57%，提升明显但并非第一）；
- **环境是文本代理**：无视觉、无连续控制、无物理动力学，与真实机器人的距离还隔着感知 grounding 和 sim2real 两道坎，论文自己也承认这点；
- **环境多样性有限**：仅两个环境家族，State-Return 暴露的长程空间记忆短板说明"大脑"还缺记忆系统的配合；
- **模型与环境的开放情况未说明**：技术报告未提及权重或环境是否开源。

### 4.4 值得关注的后续

论文结尾给了两个方向：一是用同一团队的 **Engagement Process** 框架（arXiv:2605.11484）把离散的"观测-动作"步进交互改成连续的环境互动，更贴近真实世界的时间结构；二是把物理环境与软件环境（coding agent）统一到一个交互智能模型里，甚至**让可执行代码本身成为机器人的动作接口**——这个"code as action"的想法与当前 agent 领域的趋势高度共振。

## 五、总结

Athena-Brain-8B 一句话概括：

> **用"通用 SFT → 通用 RL（带 token 预算奖励）→ 具身专家（可执行环境闭环 RL）→ 谱系感知模型合并"的四阶段后训练，把 Qwen3-8B-Base 改造成一个通用能力不降、具身交互同规模断层领先、且回复极短的端侧机器人大脑。**

它的价值不在某个单点创新，而在于给出了一份**完整、诚实、消融充分的"机器人大脑"后训练食谱**——特别是推理效率的显式优化、闭环具身 RL 的工程细节、以及模型合并的谱系判据，三部分单独拿出来都有复用价值。对于"小模型能否同时做好通用智能与具身交互"这个问题，它给出了迄今最干净的肯定答案之一。
