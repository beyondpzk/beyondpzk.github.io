# Hy-Embodied-VLM-1.0：面向物理世界 Agent 的高效具身基础模型

> **论文**：*Hy-Embodied-VLM-1.0: Efficient Physical-World Agents*  
> **作者**：Ziyi Wang, Xumin Yu, Yongming Rao, Yonggen Ling, Yunheng Li, Oran Wang, Mingqi Gao, Yuchen Zhou, Yves Liang, Zuyan Liu, Yani Zhang, Rui Huang, Xiaoran Xu, Bowen Yuan, Yifu Yuan, Xu Tan, He Zhang, Yufei Huang, Shenghao Zhang, Hongsheng Wu, Han Hu, Zhengyou Zhang  
> **发布时间**：2026-07-14  
> **arXiv**：https://arxiv.org/abs/2607.12894  
> **代码**：https://github.com/Tencent-Hunyuan/HY-Embodied  
> **模型**：https://huggingface.co/tencent/Hy-Embodied-VLM-1.0

## 摘要

Hy-Embodied-VLM-1.0 是腾讯 Robotics X 与 HY Vision Team 推出的**高效具身基础模型**，专为物理世界中的 Agent 设计。它基于 **Hy3-A3B** 语言骨干（MoE 架构，总参数 30B，激活约 3B）和 **Hy-ViT2** 视觉编码器，通过**动作中心能力分类法（Action-Centric Capability Taxonomy）**指导数据构建与训练。模型在 **38 个基准**上评估，其中 **19 个取得同规模最佳**，平均性能超越 Qwen3.6-A3B **4.4%**，相比前代 Hy-Embodied-0.5 MoT-2B 提升 **8.4%**。尽管仅激活 **3B 参数**，性能接近前代 32B 激活参数模型。在 R2R-CE 基准上取得 RGB-only 设置下的 SOTA，并展现强大的零样本 Object Goal Navigation 能力。

---

## 一、研究背景与动机

### 1.1 从数字 Agent 到物理 Agent

数字世界的 Agent（如网页浏览、代码生成）已取得显著进展，但物理世界的 Agent 面临独特挑战：

- **多模态感知**：需要理解图像、深度、空间关系；
- **动作推理**：需要推理"做什么"和"怎么做"；
- **环境交互**：需要理解动作对环境的影响；
- **长程决策**：需要多步规划、错误恢复、持续适应。

### 1.2 核心问题

现有 VLM 主要面向"看图回答问题"，而物理 Agent 需要**动作中心的智能**：

> **感知不是为了描述世界，而是为了在世界中行动。**

因此，Hy-Embodied-VLM-1.0 提出**动作中心能力分类法**，将具身智能分解为三个递进层次，指导模型设计与训练。

---

## 二、动作中心能力分类法

Hy-Embodied-VLM-1.0 将具身能力组织为三级层次：

### Level 1：Action-Relevant State Understanding（动作相关状态理解）

理解当前物理场景，为行动提供基础：

| 子能力 | 内容 |
|---|---|
| **物理与语义感知** | 物体识别、属性理解、深度估计、计数 |
| **空间推理** | 3D 几何、距离/方向、多视角对应、自由空间推理 |
| **机器人中心理解** | 机器人视角、任务相关物体、功能部件、可操作性 |

### Level 2：Action-Transition Reasoning（动作-转移推理）

理解动作及其对环境的局部影响：

| 子能力 | 内容 |
|---|---|
| **交互理解** | 人-机器人-物体交互识别、时序定位 |
| **动作决策与定位** | 下一步动作预测、目标物体/部件定位、轨迹生成 |
| **物理可行性与局部效应** | 动作前提条件、物理可执行性、状态变化预测 |

### Level 3：Sequential and Adaptive Reasoning（序列与自适应推理）

长程时间维度上的决策与适应：

| 子能力 | 内容 |
|---|---|
| **长程组合与规划** | 目标分解、因果排序、进度跟踪、多步技能组合 |
| **视觉-语言导航** | 语言目标跟随、空间记忆、自我运动、错误恢复 |
| **反思、修复与恢复** | 失败检测、因果分析、计划修复、重新规划 |

## 三、模型架构

### 3.1 整体结构

```
输入图像 (任意分辨率)
    ↓
[Hy-ViT2 Vision Encoder]  →  视觉特征
    ↓
[Connector]  →  投影到语言模型空间
    ↓
[Hy3-A3B MoE Language Model]  →  文本生成/推理
    ↓
输出 (答案 / 动作 / 坐标 / 推理链)
```

### 3.2 Hy3-A3B 语言骨干

- **MoE 架构**：总参数约 30B，每 token 激活约 3B；
- **高效推理**：动态路由到少量专家，保持大模型容量与小模型计算成本；
- **适合部署**：延迟敏感场景下的高效推理。

### 3.3 Hy-ViT2 视觉编码器

- **原生分辨率**：接受任意分辨率和宽高比，无需 resize；
- **保留细节**：避免图像缩放导致的信息损失；
- **与语言模型对齐**：通过 connector 投影到统一表示空间。

## 四、训练策略

### 4.1 整体训练流程

```
预训练 VLM
    ↓
[具身继续预训练]  →  θ_pt (物理世界基础能力)
    ↓
[Mid-Training & SFT]  →  θ_sft (指令跟随 + 浅层推理)
    ↓
[Stage I: Reasoning-Elicitation RL]  →  θ_rl (激发推理能力)
    ↓
[Rejection-Sampling Fine-Tuning]  →  θ_cons (巩固推理)
    ↓
[Stage II: Reward-Specialized RL]  →  θ_final (最终模型)
```

### 4.2 关键训练技术

#### 1. 具身继续预训练

- 在通用 VLM 基础上，注入物理世界能力；
- 数据涵盖：2D/3D grounding、检测、深度估计、分割、指向、计数、空间对应、几何、可操作性、轨迹、规划。

#### 2. Mid-Training & SFT

- 将感知能力转化为指令跟随能力；
- 混合大量通用具身监督 + 少量高质量"思考链"数据；
- 思考链数据仅用于**激活推理格式**，不用于教授具体推理内容。

#### 3. 两阶段强化学习

**Stage I：推理激发 RL**
- 使用 GRPO 优化；
- 从 SFT 模型激发真正的具身 Agent 推理能力；
- 采用任务感知奖励（Task-Aware Embodied Rewards）。

**Stage II：奖励特化 RL**
- 在 RFT 巩固后，针对连续奖励和离散奖励分别优化；
- 连续奖励：指向、定位、轨迹、深度、度量估计；
- 离散奖励：多选、判断、排序、导航方向。

#### 4. GRPO 优化细节

| 配置 | 数值 |
|---|---|
| Group size | 16 |
| Clipping 范围 | [0.8, 1.35]（非对称） |
| 优势归一化 | 批次级标准差归一化 |
| 奖励掩码 | 零方差组掩码 |

#### 5. 任务感知奖励设计

针对不同输出结构设计奖励：

| 任务类型 | 奖励函数 |
|---|---|
| 单边界框 | IoU |
| 多目标检测 | Hungarian 匹配 + 计数惩罚 |
| 单点指向 | 距离衰减奖励（δ=200） |
| 多点定位 | Chamfer 距离指数奖励 |
| 2D 轨迹 | Fréchet 距离相似度 |
| 3D 轨迹 | 0.7 × 轨迹 + 0.3 × 深度 |
| 离散输出 | 精确匹配 |
| 连续估计 | 相对误差衰减 |
| 导航方向 | "命中且不矛盾"规则 |
| 开放推理 | LLM 评判兜底 |

## 五、实验评估

### 5.1 基准覆盖

Hy-Embodied-VLM-1.0 在 **38 个基准**上评估，覆盖：

- **具身感知**：视觉理解、深度估计、空间推理；
- **物理世界理解**：物体属性、场景理解、 affordance；
- **具身推理**：规划、导航、反思、恢复。

### 5.2 总体性能

| 指标 | Hy-Embodied-VLM-1.0 | 对比 |
|---|---|---|
| 38 个基准中第 1 名 | **19 个** | Qwen3.6-A3B 较少 |
| 38 个基准中第 2 名 | **11 个** | - |
| 平均性能 vs Qwen3.6-A3B | **+4.4%** | 最强竞争对手 |
| 平均性能 vs Hy-Embodied-0.5 MoT-2B | **+8.4%** | 前代模型 |
| 激活参数 | **3B** | 前代 A32B 的 ~1/10 |
| 性能 vs 前代 A32B | **接近** | 效率大幅提升 |

### 5.3 导航任务表现

#### R2R-CE（Vision-and-Language Navigation）

- **RGB-only 设置下 SOTA**；
- 展现强大的语言目标跟随、空间记忆、多步决策能力。

#### Matterport3D Object Goal Navigation

- **强零样本性能**；
- 无需在 ObjectNav 数据上专门训练，即可泛化到物体目标导航。

### 5.4 与同类模型对比

| 模型 | 激活参数 | 38 基准平均排名 | 特点 |
|---|---|---|---|
| **Hy-Embodied-VLM-1.0** | **3B** | **第 1** | MoE 高效架构，动作中心设计 |
| Qwen3.6-A3B | ~3B | 第 2 | 通用 VLM，非具身专用 |
| Cosmos 3-8B | ~8B | 第 3 | 世界模型导向 |
| Embodied-R1.5-8B | ~8B | 第 4 | 具身推理模型 |

## 六、数据工程

### 6.1 预训练数据

继承 Hy-Embodied-0.5 的预训练混合数据，覆盖：
- 物体 grounding、检测、深度估计、分割；
- 指向、计数、空间对应、几何；
- 可操作性、轨迹理解、规划推理。

### 6.2 SFT 数据扩展

在三级分类法指导下扩展：

| 级别 | 新增数据 |
|---|---|
| **状态理解** | 深度推理（Argoverse 2、Matterport3D、nuScenes、ScanNet++、Taskonomy）、任务条件 grounding |
| **转移推理** | 社交交互（自建 + AVA v2.2 + HICO-DET）、物体/机器人轨迹、因果推理 |
| **序列推理** | 失败感知机器人推理、视觉-语言导航（Habitat R2R-CE + DAgger） |

### 6.3 RL 数据

- 空间与度量状态推理；
- 指向、grounding、可操作性预测；
- 物体/机器人轨迹推理；
- 序列过程与导航推理。

## 七、关键洞察与局限

### 7.1 关键洞察

1. **动作中心分类法有效**：三级能力层次为数据构建和评估提供了清晰框架；
2. **MoE 架构高效**：3B 激活参数达到接近 32B 模型的性能，推理效率大幅提升；
3. **两阶段 RL 必要**：先激发推理再特化奖励，比单阶段 RL 更稳定有效；
4. **任务感知奖励关键**：不同输出结构需要不同奖励设计，统一奖励会导致次优；
5. **VLA 能力可迁移**：导航能力可以泛化到 ObjectNav 等未见任务。

### 7.2 局限

1. **未部署真实机器人**：论文主要展示基准性能，真实机器人控制效果未详细验证；
2. **导航数据有限**：VLN 数据仅基于 Habitat R2R-CE，未覆盖室外或 indoor-to-outdoor 场景；
3. **长程规划能力待验证**：虽然支持多步推理，但复杂长程任务的表现未充分展示；
4. **与 VLA 专用模型对比不足**：未与 ABot-N0、Qwen-RobotNav 等专用导航 VLA 直接对比。

## 九、结论

Hy-Embodied-VLM-1.0 是面向物理世界 Agent 的高效具身基础模型。通过**动作中心能力分类法**、**MoE 高效架构**、**两阶段 RL 训练**和**任务感知奖励设计**，它在 38 个基准上取得同规模最佳性能，平均超越最强竞争对手 4.4%，且仅激活 3B 参数。

对于具身智能研究，Hy-Embodied-VLM-1.0 的启示是：**通用具身能力比单一任务优化更重要，动作中心的设计原则可以指导模型在感知、推理、规划、适应等多个维度上均衡发展。** 其开源代码和模型为社区提供了重要的基础设施。
