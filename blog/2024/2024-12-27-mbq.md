# MBQ：模态平衡的大视觉语言模型量化

> **论文**：MBQ: Modality-Balanced Quantization for Large Vision-Language Models  
> **发布时间**：2024-12-27  
> **arXiv**：https://arxiv.org/abs/2412.19509  
> **代码**：https://github.com/thu-nics/MBQ

## 一句话总结

MBQ 发现 VLM 中语言 token 和视觉 token 的量化敏感度差异很大，因此在校准阶段按模态敏感度加权重构损失，避免低敏感视觉 token 主导量化参数，从而提升低比特 VLM 精度。

## 动机

大量 LLM PTQ 方法直接迁移到 VLM 时，把所有 token 一视同仁地用于校准。但 MBQ 观察到：

- 语言 token 对最终 loss 的梯度影响显著更大；
- 视觉 token 数量多、信息冗余，但量化敏感度相对较低；
- 若视觉 token 在校准中占比过高，量化器会过度优化视觉分布，反而牺牲语言能力。

## 核心方法

### 1. 模态敏感度建模

MBQ 在校准过程中计算语言/视觉 token 的敏感度差异，并将该差异转化为重构损失中的权重：

$$ \mathcal{L}_{\text{MBQ}} = \sum_{t} w_t \cdot \| \Delta_t \|^2 $$

其中 $w_t$ 是根据 token 所属模态和梯度信息确定的权重，$\Delta_t$ 是量化前后激活或隐藏状态差异。

### 2. 模态平衡校准

校准集不能只使用纯文本，也不能只使用纯图像。MBQ 使用图文配对数据，并支持在图片与文本之间插入纯文本 token，保证校准分布覆盖真实部署中的多模态输入。

### 3. 低比特 kernel 优化

论文实现了一个 W3 GPU kernel，把反量化和 GEMV 算子融合，减少显存读取和 kernel 启动开销。

## 关键结果

- 7B 到 70B 的多种 VLM 上，W3 配置最高提升约 **4.4%**；
- W4A8 配置最高提升约 **11.6%**；
- LLaVA-OneVision-7B 在 RTX 4090 上 W3 kernel 带来约 **1.4×** 速度提升。

## 部署视角

MBQ 对 VLM 部署的启发：

- 校准数据必须同时包含图像和文本，最好还要包含纯文本片段；
- 不同模态 token 不应共用同一套敏感度假设；
- weight-only 低比特部署中，反量化/矩阵乘法融合比单纯压缩权重更重要。

## 局限

- 模态权重需要额外统计，增加了校准流程复杂度；
- 主要面向 weight-only 和低比特 LLM 侧优化，对视觉编码器激活量化的处理相对有限；
- kernel 优化依赖目标 GPU 架构，跨平台收益需要重新评估。

## 总结

MBQ 是 VLM 量化中“模态平衡”思路的代表作。它用简单但有效的加权校准解决了 VLM 特有的模态偏差问题，并为后续 VLM PTQ 方法提供了重要基线。
