# UniNaVid：基于视频的统一具身导航 VLA 模型

> **论文**：*Uni-NaVid: A Video-based Vision-Language-Action Model for Unifying Embodied Navigation Tasks*  
> **作者**：Jiazhao Zhang, Kunyu Wang, Shaoan Wang, Minghan Li, Haoran Liu, Songlin Wei, Zhongyuan Wang, Zhizheng Zhang, He Wang  
> **发布时间**：2024-12-07  
> **arXiv**：https://arxiv.org/abs/2412.06224

---

## 摘要

UniNaVid 是一个基于**视频的视觉-语言-动作（VLA）模型**，旨在统一多种具身导航任务范式。它将导航过程建模为视频序列理解问题，利用视频中的时序信息提升长程导航性能。UniNaVid 在多个导航基准上取得强劲表现，并在 NavVerse 基准的零样本评估中成为**成功率最高的基线方法**，展现出 VLA 方法在跨上下文导航中的优势。

---

## 一、研究背景与动机

### 1.1 导航任务的碎片化

现有导航研究长期陷入"任务碎片化"：
- **VLN**：依赖长程语言-视觉对齐；
- **ObjectNav**：需要主动搜索与语义推理；
- **PointNav**：强调几何路径规划；
- **跟踪**：关注动态目标。

不同任务往往使用独立模型，限制了跨任务泛化。

### 1.2 核心洞察

UniNaVid 的核心论点是：

> **导航本质上是视频理解问题：智能体需要理解"过去看到了什么"和"未来应该往哪里走"。** 因此，用视频作为统一表示，可以自然融合多种导航任务。

与单帧图像相比，视频提供：
- **时序上下文**：帮助理解运动模式和历史路径；
- **多视角信息**：通过相机运动获得环境的多角度观测；
- **动态目标信息**：对于跟踪和避障至关重要。

---

## 二、模型架构

### 2.1 整体框架

```
视频序列 (历史观测 + 当前帧)
        ↓
[Video Encoder]  →  视频特征
        ↓
[Vision-Language Model]  →  语言指令 + 视频上下文
        ↓
[Action Decoder]  →  导航动作序列
```

### 2.2 视频编码

UniNaVid 将导航过程视为视频流：
- 输入为连续的视频帧序列；
- 使用视频编码器提取时空特征；
- 保留历史帧的时序关系，而非仅使用当前帧。

### 2.3 统一任务接口

UniNaVid 通过统一的输入输出接口支持多种任务：

| 任务 | 输入 | 输出 |
|---|---|---|
| VLN | 视频 + 语言指令 | 动作序列 |
| ObjectNav | 视频 + 目标类别 | 动作序列 |
| PointNav | 视频 + 相对坐标 | 动作序列 |
| 跟踪 | 视频 + 目标描述 | 动作序列 |

### 2.4 动作解码

- 采用自回归或扩散方式解码导航动作；
- 输出离散动作（前进/左转/右转/停止）或连续控制信号；
- 支持闭环控制，根据新观测不断更新动作。

## 三、实验评估

### 3.1 主要基准表现

UniNaVid 在多个标准导航基准上取得 SOTA 或接近 SOTA 的表现：

- **VLN-CE R2R/RxR**：在长程指令跟随任务上表现强劲；
- **ObjectNav**：在 HM3D 等基准上展现良好的泛化能力；
- **多任务统一**：证明单一模型可以同时处理多种导航任务。

### 3.2 在 NavVerse 上的零样本表现

NavVerse 将 UniNaVid 作为 **VLA 方法**的代表进行评估：

#### ObjNav

| 指标 | UniNaVid | 对比 |
|---|---|---|
| All Scenes SR | **11.62%** | 最高 |
| All Scenes SPL | **2.58** | 最高 |
| Indoor SR | 17.33% | 最高 |
| Outdoor SR | 4.88% | 最高 |
| Indoor-to-Outdoor SR | **8.42%** | 最高 |
| Collision Rate | 0.31 | 高于 SGImagineNav |

#### PlaceNav

| 指标 | UniNaVid | 对比 |
|---|---|---|
| All Scenes SR | **11.38%** | 最高 |
| All Scenes SPL | **3.30** | 最高 |
| Outdoor SR | **17.65%** | 最高 |
| Indoor-to-Outdoor SR | 3.64% | 与 LongNav-R1 持平 |
| Collision Rate | 0.16 | 较低 |

#### VLN

| 指标 | UniNaVid |
|---|---|
| All Scenes SR | **10.67%** |
| All Scenes SPL | **3.21** |
| Indoor SR | 10.67% |
| Outdoor SR | **14.00%** |
| Indoor-to-Outdoor SR | 7.33% |

### 3.3 关键发现

1. **成功率最高**：UniNaVid 在所有任务和场景类型上都是成功率最高的基线；
2. **VLA 优势**：端到端 VLA 方法在语义 grounding 上明显优于 RL 和模块化方法；
3. **碰撞率偏高**：相比 SGImagineNav，UniNaVid 的碰撞率更高，说明成功率与安全性存在 trade-off；
4. **Indoor-to-Outdoor 仍具挑战**：尽管表现最好，UniNaVid 在 indoor-to-outdoor 场景上的成功率仍显著低于纯室内或纯室外。

---

## 四、优势与局限

### 4.1 优势

- **统一架构**：单一模型处理多种导航任务，无需任务特定设计；
- **视频时序信息**：充分利用历史观测，提升长程导航性能；
- **强大的语义 grounding**：VLA 架构天然适合语言-视觉对齐；
- **零样本泛化**：在未见场景和任务上仍能保持一定性能。

### 4.2 局限

- **碰撞率较高**：端到端方法在物理约束处理上不如模块化方法保守；
- **视频计算开销**：处理视频序列比单帧图像计算量大；
- **Indoor-to-Outdoor 过渡**：跨上下文泛化仍是主要瓶颈；
- **依赖大规模数据**：VLA 模型通常需要大量演示数据训练。

## 五、与相关工作的关系

| 工作 | 与 UniNaVid 的关系 |
|---|---|
| **NaVid** | UniNaVid 的前序工作，专注于 VLN；UniNaVid 扩展到统一多任务 |
| **ABot-N0** | 同样是统一多任务 VLA，但 ABot-N0 使用 LLM + Flow Matching，UniNaVid 基于视频 |
| **Qwen-RobotNav** | 都是统一导航模型，Qwen-RobotNav 强调参数化观察接口 |
| **NavVerse** | UniNaVid 是 NavVerse 评估中成功率最高的基线 |

---

## 六、结论

UniNaVid 证明了**视频-based VLA 架构在统一具身导航中的有效性**。通过将导航建模为视频理解问题，UniNaVid 在多种任务和基准上取得强劲表现，并在 NavVerse 的零样本评估中成为成功率最高的基线。

然而，其较高的碰撞率和 indoor-to-outdoor 场景的性能下降表明：**纯端到端 VLA 在物理约束处理和跨上下文适应上仍有不足**。未来工作可能需要将 VLA 的语义理解能力与模块化方法的安全规划相结合，以实现既高效又安全的通用导航。
