# NavDP：特权信息引导的纯仿真导航扩散策略，零样本跨本体迁移

> **论文**：*NavDP: Learning Sim-to-Real Navigation Diffusion Policy with Privileged Information Guidance*  
> **作者**：Wenzhe Cai、Jiaqi Peng、Yuqiang Yang、Yujian Zhang、Meng Wei、Hanqing Wang、Yilun Chen、Tai Wang、Jiangmiao Pang  
> **机构**：上海人工智能实验室、清华大学、浙江大学、香港大学  
> **发布时间**：2025-05-13（arXiv v1；v3 为 ICRA 2026 相机版）  
> **arXiv**：https://arxiv.org/abs/2505.08712  
> **代码**：https://github.com/InternRobotics/NavDP （CC BY-NC-SA 4.0，非商用）  
> **主页**：https://wzcai99.github.io/navigation-diffusion-policy.github.io/

## 一句话总结

NavDP（Navigation Diffusion Policy）完全用仿真数据训练端到端导航扩散策略：输入单帧 RGB-D + 目标，扩散头生成一批 24 步候选轨迹，再用仿真特权信息（全局 ESDF）训练的 **critic 函数**给候选轨迹打分筛选、选最优执行——这个"生成 + 批判"结构弥补了纯模仿学习没有负反馈的缺陷，零样本迁移到四足（Go2）、轮式（Dingo）、人形（G1/R1）多种本体，真机 >10Hz 推理、最高 2.0 m/s。

## 动机

- **模块化导航栈**（定位+建图+规划级联）：系统延迟、误差累积、超参调试重；
- **学习型方法**（GNM/ViNT/NoMaD）：依赖昂贵的真实遥操作数据，难规模化；且 NoMaD 这类扩散策略**无法在测试时基于局部信息做轨迹筛选**——生成方差在序贯决策中累积成安全问题；
- **模仿学习缺少负反馈**：只学"专家怎么做"，不学"这么做会有什么后果"。

NavDP 的两张牌：① 纯仿真数据引擎把采集成本打掉；② 用仿真里的特权信息（全局 ESDF）训一个 critic，让策略在部署时能自我评估轨迹安全性。

## 核心方法

### 1. 架构与目标形式

- **输入**：单帧 RGB-D（v3 改为 N 帧 RGB + 单帧深度）+ 导航目标；RGB 用预训练 DepthAnything ViT 编码，深度用从零训练的 ViT，深度值裁剪到 0.1~5m 缩小 sim-to-real 差距；transformer decoder 压缩为 16 个融合 token；
- **输出**：24 步未来路点，表示为相对位姿变化 $(\Delta x, \Delta y, \Delta\omega)$；
- **四种零标注成本目标**（全部可从轨迹数据自动导出）：Point goal（2D 相对坐标）、Image goal、Trajectory goal（投影到第一视角的期望轨迹）、No goal（漫游避障）。

### 2. 扩散策略头

两层 transformer encoder + conditional U-Net + DDPM，多任务扩散训练：

$$\mathcal{L}^{act}=\sum_{m}\mathrm{MSE}\big(\epsilon_k^m,\ \epsilon_\theta^m(x_0+\epsilon_k^m,\,k)\big)$$

### 3. Critic 函数（关键创新）

与扩散头共享 backbone，但**不 attend 目标 token**（goal-agnostic，只评估安全性）。训练时构造负样本——对原始轨迹施加随机旋转并插值 $\hat{\tau}=(1-\beta)\tau+\beta\tau^r$，用仿真特权信息（全局 ESDF）打标签：

$$V(\hat{\tau})=-\sum_{k=0}^{T}\mathbb{I}(d_{\hat{\tau}}^k<d_{safe})+\alpha\sum_{k=0}^{T-1}(d_{\hat{\tau}}^{k+1}-d_{\hat{\tau}}^{k})$$

直觉：惩罚进入 0.5m 安全半径的轨迹点，奖励"越来越远离障碍"的趋势。

**两阶段推理**：扩散头生成一批候选轨迹 → critic 打分选最优执行。生成保多样性，批判保安全。消融显示 critic 作为训练辅助损失和测试时筛选**两者都重要**（训了不用比不用还差的反面：不训 critic 更差）。

### 4. 数据引擎

机器人建模为 0.25m 半径圆柱刚体 + 双轮差速；相机高度 0.25~1.25m、俯仰角、纹理、光照全随机化；轨迹经 ESDF → A* → 贪心细化 → 三次样条平滑，BlenderProc 渲染逼真 RGB-D。

- v1：1244 场景（3D-FRONT + MP3D），56K 轨迹，10M 图像，363 km；
- **v3（ICRA 版）**：3154 场景（3D-FRONT/HSSD/HM3D/Replica/Gibson/MP3D），**200K+ 轨迹、40M 图像、1627 km / 452 小时**，效率约 2500 条轨迹/GPU/天，号称比真实采集高效 20 倍。

## 关键结果

**仿真闭环**（IsaacSim 物理仿真，Hospital/Office/Warehouse 等场景，Dingo/Go2/R1 三平台）：

- **Point-goal**：mSR/mSPL 70.4/58.6，优于 ViPlanner（65.6/55.4）、EgoPlanner（64.7/54.6）、iPlanner（48.2/40.7）、PointNav（22.1/16.6）；
- **No-goal 探索**：运行时间/覆盖面积全面远超 GNM、ViNT、NoMaD——NoMaD 即使在 NavDP 的仿真数据上微调也追不上，说明增益来自方法而非数据。

**真机零微调**：Go2、Galaxea R1、Unitree G1 三平台，室内外含动态行人干扰；推理 >10Hz（RTX 5080 笔记本），最高 2.0 m/s。

**Real-to-Sim 增强**：用 3DGS（Scaffold-GS + Trellis）重建部署场景生成约 4K 条域内轨迹，混入约 27% 后真机成功率 **50%→80%**——这是低成本适配新场地的实用配方。

## 局限

- 不支持语言指令目标（作者计划后续引入 VLN 数据；后续工作 X-NavDP 引入 RL 后训练）；
- 无显式本体编码——狭窄环境中"相机避开了但机身撞上"；
- 输出轨迹级动作，仍需外部 locomotion 策略跟踪；只处理 2D 平面可行路径，无法跨障攀爬。

## 与巡逻方案执行器选型的关系

NavDP 是我们巡逻方案（[室内巡逻执行流程：从示教建图到局部绕障](/blog/2026/2026-09-29-indoor-patrol-execution)）执行层的又一个有力候选，与 NoMaD 的对照值得记录：

| | NavDP | NoMaD |
|---|---|---|
| 传感器 | RGB-D | 纯 RGB |
| 训练数据 | 纯仿真（40M 图像） | 100h+ 真实遥操作 |
| 轨迹安全 | ✅ critic 筛选（测试时自检） | ❌ 生成即执行 |
| 目标接口 | Point/Image/Trajectory/No goal 四种 | 图像目标 + 探索（Goal Masking） |
| 本体 | 四足/轮式/人形零样本 | 主要轮式验证 |
| 权重 | 有（表单申请），非商用 | 开源，宽松 |

三点启发：

1. **"生成 + critic 筛选"比纯生成更适合安全敏感场景**——critic 是 goal-agnostic 的，意味着它可以独立评估任何来源的候选轨迹（包括别的策略生成的），这个模块思想可直接移植；
2. **Real-to-Sim 域内轨迹混入 27% 把真机成功率从 50% 拉到 80%**——比真实遥操作便宜得多的场地适配手段，对巡逻方案"新场地快速适应"有直接参考价值；
3. NavDP 的自我定位是 VLA 系统的 **System-1 快执行层**——与我们架构中"VLA/VT&R 管记忆与目标，执行器管局部避障"的分层完全一致，且它的 Point goal 接口正好能消费 Reloc3r + 帧间距算出的机体系点目标。
