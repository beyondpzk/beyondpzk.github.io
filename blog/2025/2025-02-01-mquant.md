# MQuant：多模态大语言模型的全静态量化

> **论文**：MQuant: Unleashing the Inference Potential of Multimodal Large Language Models via Full Static Quantization  
> **发布时间**：2025-02-01  
> **会议**：ACM MM 2025  
> **arXiv**：https://arxiv.org/abs/2502.00425  
> **代码**：https://github.com/StiphyJay/MQuant

## 一句话总结

MQuant 是面向多模态大语言模型（MLLM）的 PTQ 框架，通过模态专用静态 scale、保序 token 重排和 Hadamard 旋转幅值抑制，实现 W4A8 全静态量化。

## 动机

MLLM 部署有三个 PTQ 特有难点：

1. 视觉 token 数量大，推理延迟高；
2. 视觉与文本 token 的激活分布差异大；
3. 采用在线 Hadamard 旋转等技巧时，权重会出现新的极端 outlier。

直接复用 LLM PTQ 很难同时解决这三个问题。

## 核心方法

### 1. Modality-Specific Static Quantization（MSQ）

MSQ 为视觉 token 和文本 token 分配不同的静态量化 scale，避免单一 scale 被模态分布差异拉坏。

### 2. Attention-Invariant Flexible Switching（AIFS）

通过重排 token 顺序来消除 token-wise scale 计算，同时保持 causal attention 语义不变。这样既能降低动态 dequant 开销，又不破坏注意力关系。

### 3. Rotation Magnitude Suppression（RMS）

Hadamard 旋转可以压低激活 outlier，但也可能把能量转移到权重上。RMS 针对在线旋转后的权重幅值进行抑制，减少新的权重 outlier。

## 关键结果

- 在 Qwen-VL、MiniCPM-V、CogVLM2 等 5 个主流 MLLM 上验证；
- W4A8 下接近浮点精度，性能退化小于约 **1%**；
- 推理延迟最高降低约 **30%**。

## 部署视角

MQuant 强调“全静态”量化：

- 推理时不需要逐 token 动态 scale，部署路径更简单；
- 对视觉 token 和文本 token 分别配置 scale，更符合 MLLM 真实分布；
- 与旋转类方法结合时，需要额外监控权重侧 outlier。

## 局限

- 模态专用 scale 会增加模型状态和管理复杂度；
- 旋转类变换仍会带来权重分布变化，RMS 的有效性依赖具体模型；
- 主要面向 LLM 主干，视觉编码器的量化细节仍需要和上游模型一起验证。

## 总结

MQuant 是 MLLM 全静态量化的重要尝试，核心贡献是把模态差异和旋转 outlier 同时纳入量化设计，而不是简单把 LLM PTQ 套到多模态模型上。
