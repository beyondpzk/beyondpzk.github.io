# VLMQ：Token 显著性驱动的视觉语言模型 PTQ

> **论文**：VLMQ: Token Saliency-Driven Post-Training Quantization for Vision-language Models  
> **发布时间**：2025-08-05  
> **arXiv**：https://arxiv.org/abs/2508.03351

## 一句话总结

VLMQ 面向 VLM 激活中的“视觉 token 过表示”和“模态分布差距”两个特点，提出用梯度驱动的 token 重要性因子，让量化优化优先保护显著 token，而不是对大量冗余视觉 token 平均用力。

## 动机

VLM 激活和 LLM 激活有两点显著不同：

1. **视觉过表示**：视觉 token 数量远多于文本 token，且很多 patch token 信息冗余；
2. **模态差距**：视觉与文本 token 在特征空间中的分布差异很大。

若沿用 LLM PTQ，所有 token 使用同一量化目标，冗余视觉 token 会稀释优化信号，最终导致低比特下多模态任务精度下降。

## 核心方法

### 1. 梯度驱动的 token 重要性

VLMQ 引入一个 per-token importance factor，用梯度信息判断哪些 token 对最终输出更重要。重要 token 在量化误差目标中获得更高权重，冗余 token 则被抑制。

### 2. 轻量块级反向传播

直接对全部 token 计算重要性代价很高。VLMQ 使用轻量块级反向传播获取 importance factor，降低校准成本。

### 3. 重要性感知重构目标

量化参数搜索被重写为重要性加权形式：

$$ \min_{\Theta} \sum_i I_i \cdot \| f_i(W) - f_i(\hat{W}) \|^2 $$

其中 $I_i$ 是第 $i$ 个 token 的显著性，$f_i$ 表示 token 对应的激活映射。

## 关键结果

- 覆盖 0.5B 到 32B 的多种 VLM；
- 在 8 个多模态基准上取得 SOTA；
- 2-bit 量化下 MME-RealWorld 提升约 **16.45%**。

## 部署视角

VLMQ 说明 VLM 低比特部署不能只处理权重分布，还要处理 token 级激活差异：

- 量化校准前可以先做 token 显著性分析；
- 视觉 token 冗余度越高，重要性加权带来的收益越大；
- 该思路还可以和视觉 token 剪枝、缓存策略组合使用。

## 局限

- 重要性因子依赖反向传播，严格意义上是轻量 PTQ 流程，不是完全前向零成本；
- token 重要性在不同任务间可能变化，需要任务相关校准数据；
- 未显著改变模型结构，但若没有 kernel 支持，低比特收益可能无法完全兑现。

## 总结

VLMQ 把“token 级显著性”引入 VLM 量化，是目前 VLM PTQ 中比较系统地处理视觉冗余和模态差距的工作之一。
