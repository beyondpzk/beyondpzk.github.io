# Bi-VLM：把 VLM 权重 PTQ 推到 2-Bit 以下

> **论文**：Bi-VLM: Pushing Ultra-Low Precision Post-Training Quantization Boundaries in Vision-Language Models  
> **发布时间**：2025-09-23  
> **arXiv**：https://arxiv.org/abs/2509.18763

## 一句话总结

Bi-VLM 面向 VLM 提出一种 ≤2-bit 的超低比特权重 PTQ 方法，通过高斯分位数对权重进行非均匀分组，再用显著性感知的混合量化分别约束 outlier 和 inlier 子集。

## 动机

VLM 同时包含视觉编码器和 LLM 主干，模型体积大，在边缘设备上部署很困难。低比特 weight-only 量化可以大幅降低显存，但 2-bit 以下通常精度崩坏，原因在于：

- 权重分布存在少量高显著 outlier；
- 普通均匀量化无法同时保留 outlier 和大量 inlier；
- VLM 中视觉与语言任务对量化误差的容忍度不同。

## 核心方法

### 1. 高斯分位数权重分组

Bi-VLM 不按固定阈值切分权重，而是按高斯分布分位数把权重分成：

- **Outlier / salient 子集**：保留高显著权重；
- **多个 inlier / unsalient 子集**：覆盖大部分低显著权重。

每个子集的权重数量与其分布分位数对应，避免极端权重把量化范围拉得过大。

### 2. 显著性感知混合量化

量化过程对 scaler 和 binary 矩阵施加不同约束：

$$\min_{s, B} \| W - s \odot B \|_F^2 + \lambda \cdot R(s, B)$$

其中 $s$ 是缩放参数，$B$ 是低比特矩阵，$R$ 是显著性感知的约束项。不同权重组使用不同压缩强度，从而在极低位宽下保留关键参数。

### 3. 量化后的视觉 token 剪枝

作者发现量化后的 VLM 图像 token 存在大量冗余，约 **90%–99%** 可以被进一步剪枝，从而在不明显损失精度的情况下继续降低计算量。

## 关键结果

- 在多个 VLM 的语言模型部分，VQA 任务相对 SOTA 提升 **3%–47%**；
- 对整个 VLM 的评估相对 SOTA 提升 **4%–45%**；
- 量化后的视觉 token 剪枝空间约为 **90%–99%**。

## 部署视角

Bi-VLM 适合：

- 显存极度受限的端侧/边缘 VLM 部署；
- weight-only 超低比特服务；
- 希望同时压缩权重和减少视觉 token 计算量的场景。

## 局限

- 非均匀分组和显著性约束增加了 PTQ 流程复杂度；
- 指标区间跨度较大，不同模型/任务收益不均衡；
- 视觉 token 剪枝收益依赖任务和图像内容。

## 总结

Bi-VLM 是 VLM 超低比特量化的重要探索，展示了 ≤2-bit 权重 PTQ 在 VLM 上的可行性，并发现量化后的视觉 token 冗余可进一步压缩。
