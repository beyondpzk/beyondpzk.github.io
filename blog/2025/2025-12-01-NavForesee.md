# NavForesee：统一 VLM 世界模型，分层规划 + 双视界导航预测

> **论文**：*NavForesee: A Unified Vision-Language World Model for Hierarchical Planning and Dual-Horizon Navigation Prediction*
> **作者**：Fei Liu*、Shichao Xie*、Minghua Luo、Zedong Chu†、Junjun Hu、Xiaolong Wu†、Mu Xu（高德，阿里巴巴集团）
> **arXiv**：https://arxiv.org/abs/2512.01550（v1 2025-12-01，v2 2026-03-13）

---

## 摘要

NavForesee 是高德（Amap）团队提出的 VLN 框架，核心思想是**在单个 VLM 内统一高层语言规划与预测性世界模型想象**。模型以完整指令和历史观测为条件，同时进行任务分解、进度跟踪、子目标生成（规划），并在两个时间尺度上"想象"未来：短期环境动态预测与长期导航里程碑预测（预见）。结构化规划指导有针对性的预测，想象的未来又为动作决策提供丰富上下文，形成"感知—规划/预测—动作"的内部闭环。仅使用公开的 R2R-CE 和 RxR-CE 数据训练，NavForesee 在 R2R-CE Val-Unseen 上取得 **SR 66.2%、OSR 78.4%、NE 3.94m**，OSR 为两个基准上所有方法中最高。

## 1. 动机：VLN 智能体的两大缺陷

复杂自然语言指令引导的**长程具身导航**中，现有智能体失败率居高不下，根源在于两点：

1. **规划与记忆缺陷**：可部署的 VLM 上下文窗口和规划能力有限，在长程任务中容易"迷路"——失去对已走路程和剩余任务的跟踪。
2. **缺乏预测性先见（predictive foresight）**：当前模型本质上是反应式（reactive）的，无法预判未来环境状态来主动引导动作。

已有研究分别在两条路线上推进：一条通过精选数据和 CoT 提示增强 VLM 推理；另一条构建世界模型预测未来状态。但两条路线是**割裂**的：

- 纯 VLM 智能体容易产生**语义幻觉**——规划与视觉现实脱节；
- 无语言引导的世界模型容易出现**语义漂移**——预测偏离指令目标。

NavForesee 的立场是：**VLM 规划与预测先见不应分离，而应在单一 VLM 内统一并相互强化**。

### 人类导航的启发

人类导航不是连续的底层过程，而是**以里程碑（milestone）为中心的层次化过程**：人朝着一系列有意义的地标前进，基本忽略路径之间的细枝末节。NavForesee 模仿这一策略，通过两个协同功能运作：

- **分层语言规划**：作为规划器，将导航任务总结为已完成的子指令、识别当前子指令、并将下一步制定为语义动作"主干（trunk）"；
- **双视界预测先见**：作为世界模型，长期预测当前子指令完成时的关键视觉特征（即 envision 下一个里程碑），短期预测即时未来特征以增强局部感知，支撑鲁棒避障和环境动态理解。

## 2. 分层规划数据集构建

为了让 VLM 学会分层规划，作者构建了一个专门的指令导航分层规划数据集：

- **数据来源**：公开的 R2R-CE（10k episodes）和 RxR-CE（20k episodes），包含配对的自然语言指令与完整图像观测序列；
- **标注工具**：使用 **Gemini 2.5 Pro**，通过定制 prompt（指定角色、任务、分析步骤和输出格式）将每条长指令分解为顺序子指令，并识别代表导航里程碑的稠密关键帧链；对于长距离直行或急转弯路径，要求插入中间里程碑以保持视觉连续性；
- **标签结构**：沿轨迹采样航点，每个航点标注三元组——(1) 导航摘要（已完成的子指令）、(2) 未来规划（下一条指令）、(3) 语言动作（forward / left / right / stop）；
- **规模**：RxR-CE 约 **130 万**样本，R2R-CE 约 **20 万**样本；对过多的直行样本下采样、对停止动作样本做增广以平衡数据。

## 3. 模型架构

```
┌────────────────────────────────────────────────────────────────┐
│              NavForesee (Qwen2.5-VL-3B-Instruct)               │
├──────────────────────────────┬─────────────────────────────────┤
│   分层语言规划               │   世界模型双视界预测            │
│   自回归文本生成             │   dream queries + 结构化注意力  │
│   • 导航摘要                 │   • 短期: depth/DINOv2/SAM      │
│   • 进度跟踪                 │   • 长期: depth/DINOv2/SAM      │
│   • 下一步子目标             │   • 轻量 ViT 解码器             │
├──────────────────────────────┴─────────────────────────────────┤
│              动作策略: action query → 逆动力学 MLP             │
│              输出 K=5 个航点 [x, y, sinθ, cosθ, stop]          │
└────────────────────────────────────────────────────────────────┘
```

### 3.1 骨干与统一训练

以 **Qwen2.5-VL-3B-Instruct** 为骨干，定义两类训练目标：**分层规划训练**（文本规划数据直接送入 Qwen 做自回归训练，沿用原始多模态编码器）与**世界模型训练**（引入位置编码器、dream queries 和 action query）。两类数据**交错（interleaving）训练**，使模型在保持多模态规划能力的同时扩展视觉特征生成能力。

### 3.2 Dream Queries 与结构化注意力掩码

dream queries 共 **6 个子集**：短期/长期 × depth/DINOv2/SAM，每个子集 64 个 token；另有 1 个 action query token。为避免不同类型预测相互污染，设计了**结构化注意力掩码**：

- 每类 dream query（depth、语义）显式拆分为短期与长期两部分；
- **长期预测依赖短期预测**（以其为引导保证时间一致性）；
- depth 与语义 query 之间的互相注意力被**掩码**，防止跨模态泄漏；
- **action query 可关注所有信息**——历史上下文和两个视界的 dream queries，以做出全局一致的导航预测。

### 3.3 双视界世界模型预测

受 DreamVLA 等潜空间世界模型启发，NavForesee **刻意避免昂贵的像素级生成**，转而预测紧凑的高层特征——depth（几何）与 DINOv2/SAM（语义）：

- **短期预测**：固定视界 k=5 步（与预测航点数一致）；
- **长期预测**：目标是导航里程碑，视界 $M_t$ 是**自适应**的，取决于当前进度距下一里程碑的距离。子指令在分层规划中隐式学习，规划感知的隐藏状态编码了当前子目标意图，通过对规划与预测任务的交错训练实现对齐。

形式上，短期 embedding $E_S = f(l, O_{t-H:t}, h(s_{t-H:t}) \mid Q_S)$ 先生成，长期 embedding $E_L$ 以短期为条件自回归生成，再经轻量 2 层 ViT 解码器解码为预测特征（depth 特征再经 VQ-VAE 解码器渲染为深度图）。

### 3.4 预测式动作策略学习

基于**逆动力学**原理：给定两个相邻状态 $o_t, o_{t+1}$ 可推断中间动作。引入可学习的 action query $Q_a$，与 dream queries 及多模态输入拼接后经骨干得到动作 embedding $E_a$，再由逆动力学模型（2 层 Transformer + 简单 MLP 头）以双视界预测特征为主要条件，输出 K=5 个未来航点，每个航点为 $[x, y, \sin\theta, \cos\theta, c]$（平面位置、朝向角、停止标志）。

### 3.5 训练目标

总损失由三项组成：深度预测用像素级 **SiLogLoss**，语义特征与动作用 **MSE**：

$$L = \alpha L_d + \beta L_c + L_a$$

其中 $\alpha=0.25$、$\beta=0.3$。训练细节：batch size 4，最多 20 帧图像观测，AdamW（lr 1e-5），ViT 参数冻结，64 张 NVIDIA H20 训练 3 个 epoch。

## 4. 实验结果

### 4.1 与 SOTA 对比（Val-Unseen）

| 方法 | R2R-CE NE↓ | R2R-CE OS↑ | R2R-CE SR↑ | R2R-CE SPL↑ | RxR-CE NE↓ | RxR-CE SR↑ | RxR-CE SPL↑ |
|---|---|---|---|---|---|---|---|
| ETPNav*（离散航点） | 4.71 | 65.0 | 57.0 | 49.0 | 5.64 | 54.7 | 44.8 |
| HNR* | 4.42 | 67.0 | 61.0 | 51.0 | 5.50 | 56.3 | 46.7 |
| NaVILA | 5.22 | 62.5 | 54.0 | 49.0 | 6.77 | 49.3 | 44.0 |
| StreamVLN | 4.98 | 64.2 | 56.9 | 51.9 | 6.22 | 52.9 | 46.0 |
| CorrectNav | 4.24 | 67.5 | 65.1 | 62.3 | 4.09 | 69.3 | 63.3 |
| **NavForesee** | **3.94** | **78.4** | **66.2** | 59.7 | 4.20 | 66.3 | 53.2 |

要点：

- **R2R-CE 上达到 SOTA 的 SR/OSR**：相比此前最好的 CorrectNav，SR +1.1%、OSR +10.9%、NE 降低 0.3m；SPL 略低（59.7 vs 62.3）；
- **RxR-CE 上略逊于 SOTA**（SR 66.3 vs CorrectNav 69.3），作者归因于仅使用 R2R-CE/RxR-CE 公开数据训练，而其他方法借助多样大规模数据增强泛化；
- **OSR 在两个基准上均为所有方法中最高**，说明世界模型预测让智能体能更好地探索环境、走到目标附近——失败更多出在停止判定而非寻路。

### 4.2 消融实验

**模块消融（R2R-CE Val-Unseen）**：

| VLM 规划 | 长期预测 | 短期预测 | SR↑ | OSR↑ | NE↓ | SPL↑ |
|---|---|---|---|---|---|---|
| ✓ | ✓ | ✓ | **66.2** | **78.4** | **3.94** | **59.7** |
| | ✓ | ✓ | 48.8 | 75.5 | 5.61 | 39.4 |
| | | ✓ | 47.8 | 75.3 | 5.77 | 36.1 |
| ✓ | | ✓ | 58.6 | 76.4 | 4.47 | 50.1 |
| | | | 52.6 | 67.4 | 5.53 | 46.7 |

- 去掉 VLM 规划，SR 从 66.2% 暴跌至 48.8%，SPL 掉超 16 个点——显式指令分解与进度跟踪贡献最大；
- 去掉长期（里程碑）预测，SR 降至 58.6%——里程碑先见提供长程战略引导；
- 有意思的是，三者全去掉（52.6%）反而比"仅短期预测"（47.8%）好，说明**没有规划引导的裸预测可能引入噪声**，预测必须与规划协同才有价值。

**短期视界消融**：k=5（与动作空间匹配）最优（SR 66.2%），k=4 降至 64.1%，k=3 降至 56.5%。

### 4.3 定性分析

- **短期预测**：深度图虽因像素级监督限制略显粗糙，但保留了场景全局几何与空间布局，能忠实捕捉上下楼梯、进出房间、急转/缓转等运动；语义预测（DINOv2 特征经预训练分割头可视化）与真值标签高度对齐；
- **长/短期结合**：模型在直行和转弯场景下都能可靠外推未来几何与语义结构。一个亮点案例是：智能体只是**快速瞥了一眼房间**，模型就能生成连贯的内部想象——准确推断床的相对形状与位置、估计房间深度分布，展现了对未观测空间区域的推理能力；
- **分层规划输出**：在完整 episode 的每一步，模型都能识别沿途里程碑、总结已完成子指令、并生成与整体指令一致的下一步子指令，且规划输出精确简洁。

## 5. 点评

- **核心贡献**在于把"VLM 分层规划"与"世界模型预测"装进**同一个 3B VLM**，用交错训练让两者共享表征、互相强化，而不是堆叠两个独立模块。消融证明这种统一是有效的：规划指导预测的方向（避免语义漂移），预测为规划/动作提供环境先见（避免语义幻觉）。
- **里程碑式的长期预测**是区别于 NavMorph、HNR 等已有导航世界模型的关键设计：自适应视界 $M_t$ 把"预测多远"与"子目标进度"绑定，契合人类以地标为中心的导航方式。
- **工程上的克制**也值得注意：不生成像素、只预测 depth + DINOv2 + SAM 紧凑特征；动作头只是 MLP；骨干仅 3B。仅用公开数据就在 R2R-CE 上超过使用更大规模数据的方法，说明架构设计的收益。
- **局限**：RxR-CE（多语言、更复杂轨迹）上泛化不足；停止判定偏弱（OSR 远高于 SR）；推理时 VLM 需要同时维护规划与多组 dream query 的生成，延迟开销论文未详细报告；真实机器人实验缺失。
