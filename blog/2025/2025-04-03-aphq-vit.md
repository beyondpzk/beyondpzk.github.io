# APHQ-ViT：平均扰动 Hessian 重建 + GELU→ReLU，只用 uniform 量化器打穿 ViT 3-bit

> **论文**：APHQ-ViT: Post-Training Quantization with Average Perturbation Hessian Based Reconstruction for Vision Transformers  
> **发布时间**：2025-04-03  
> **会议**：CVPR 2025  
> **机构**：北京航空航天大学（虚拟现实技术与系统全国重点实验室 / 计算机学院）  
> **arXiv**：https://arxiv.org/abs/2504.02508  
> **代码**：https://github.com/GoatWu/APHQ-ViT

## 一句话总结

APHQ-ViT 指出 BRECQ 系 Hessian-guided 重建损失中的 Hessian 是"近似再近似"的错误估计，改用扰动 + 中值定理从定义出发数值估计对角 Hessian 并跨样本平均（APH loss），再把 MLP 的 GELU 永久替换为 ReLU 做逐层重建（MR），全程只用标准 uniform 量化器就把 ViT 的 W3A3 平均精度拉高 7.21%。

## 动机

重建类 PTQ（BRECQ/QDrop）在 CNN 上很成功，但搬到 ViT 上效果不佳，论文把原因归结为两点：

**1. Hessian 估计不准。** BRECQ 的 Hessian-guided loss 来自任务损失的 Taylor 展开，其中叠了两层近似：用 FIM 近似 Hessian、再用输出梯度的平方近似 FIM 对角元。这两层近似只在"任务损失为交叉熵、且模型预测分布与真实分布高度吻合"时才成立——实践中不成立，也无法推广到检测/分割任务。实证上，这个 loss 在多个 ViT 上**甚至不如朴素 MSE**（W3A3 ViT-B：BH 66.62 vs MSE 73.79）。另外 MSE 对所有 token/通道一视同仁，忽略了 class token 的关键性。

**2. post-GELU 激活难量化。** GELU 后激活分布高度不均衡：负值密集堆积在 $[-0.17, 0]$ 的极窄区间，正值稀疏长尾，某些层激活范围可达 40。已有的专用量化器（twin-uniform、任意底数 log 等）需要专用硬件，实用性差。

## 核心方法

### 1. Average Perturbation Hessian（APH）Loss

只保留两条基础假设：Taylor 展开可忽略三阶及以上项；各输出元素影响独立（对角 Hessian 足够）。推导链条：

- 把量化重建看作小校准集上的知识蒸馏（分类用输出 logits 的 KL 散度），这类损失满足 $\mathcal{L}\ge 0$ 且仅在 $\hat{O}=O$ 处取零，因此一阶项**严格为零**（无需"模型已收敛"假设）：

$$\mathcal{L}(O+\epsilon)-\mathcal{L}(O)\approx\frac{1}{2}\epsilon^\top\bar{H}^{(O)}\epsilon$$

- 用扰动 + 中值定理数值估计对角 Hessian：取 $\Delta O=10^{-6}$，对 block 输出做 $O^+=O+\Delta O$、$O^-=O-\Delta O$ 两次扰动，过网络剩余部分前向/反传得 Jacobian：

$$\bar{H}^{(O)}_{i,i}\approx\frac{\bar{J}^{(O^+)}_i-\bar{J}^{(O^-)}_i}{2\cdot\Delta O_i}$$

- 单样本 Hessian 波动大导致训练不稳，对全部 $N$ 个校准样本取平均：

$$\mathcal{L}_{\mathrm{APH}}=\sum_i(\widehat{O}_i-O_i)^2\cdot\bar{H}_{i,i},\qquad \bar{H}_{i,i}=\frac{1}{N}\sum_{n=1}^N\bar{H}^{(O^{(n)})}_{i,i}$$

理论保证：APH 是 PH 的无偏估计（Theorem 3.1），且梯度方差更小（Theorem 3.2），收敛更快更稳。与 BRECQ 路线的本质区别是**从定义直接数值估计 Hessian**，彻底消除 FIM 近似的误差，且天然可推广到检测/分割；计算只多一次前向+反向，开销可忽略。

### 2. MLP Reconstruction（MR）：GELU 永久换 ReLU

- **做法**：把 MLP 中所有 GELU 永久替换为 ReLU（推理期也保持 ReLU），然后逐层做 feature distillation 重建，用 APH 作为重要性权重对齐 ReLU 版输出与原始 GELU 版输出。
- **为什么可行**：深层网络用 GELU 是为了规避 dying ReLU；MR 逐层重建，每层很浅，没有这个问题，ReLU 的表达能力足够。
- **为什么好量化**：ReLU 把堆积在 $[-0.17,0]$ 的负值直接截零，再取正值的 0.99 分位数 clamp 压缩范围，post-GELU 激活变成规整的非负窄分布。
- **总损失**：Direct（未截断分支，防止硬截断区梯度消失）+ Clamp 分支加权（$\alpha=2$），均用 APH 加权。

仅做 MR、不做任何量化的 FP32 模型几乎不掉点——ViT-B 甚至 84.54→84.84 反超原模型。附带收益：ReLU 可与前一线性层融合，推理反而更快（CPU W8A8 下 DeiT-B 相比 GELU 版再快约 10%）。

### 3. 量化设置

- 量化器：权重 channel-wise uniform，激活 layer-wise uniform（含 attention map）——**全程标准线性量化器**，无任何定制算子；
- 流程：block-wise 重建，每个 block 先 MR 再基于 QDrop 的量化重建（AdaRound 权重 + 随机丢量化），两个阶段都用 APH loss；
- 校准集：ImageNet 1024 张无标注图，COCO 256 张；MR 与重建各 20000 迭代。

## 关键结果

**ImageNet 分类 W3A3（top-1 %）**：

| 方法 | ViT-S | ViT-B | DeiT-T | DeiT-S | DeiT-B | Swin-S | Swin-B |
|---|---|---|---|---|---|---|---|
| RepQ-ViT | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 |
| I&S-ViT | 45.16 | 63.77 | 41.52 | 55.78 | 73.30 | 74.20 | 69.30 |
| DopQ-ViT | 54.72 | 65.76 | 44.71 | 59.26 | 74.91 | 74.77 | 69.63 |
| **APHQ-ViT** | **63.17** | **76.31** | **55.42** | **68.76** | **76.31** | **76.10** | **78.14** |

W3A3 比第二名 DopQ-ViT 平均高 7.21%，DeiT-T 上高 10.71%。W4A4 同样全面领先：ViT-S 76.07 / ViT-B 82.41 / DeiT-T 66.66 / DeiT-S 76.40 / DeiT-B 80.21 / Swin-S 81.81 / Swin-B 83.42。

**COCO 检测/分割（W4A4）**：Mask R-CNN Swin-T 38.9/38.1（FP 46.0/41.6）、Cascade Mask R-CNN Swin-S 50.3/43.7（FP 51.9/45.0），在只用 uniform 量化器的方法中最好，与使用定制量化器的方法持平或更高。

**消融亮点**：
- QDrop(MSE) → +APH → +APH+MR：ViT-S W3A3 从 38.31 → 59.11 → 63.17，APH 一项在小模型上提升 15~20 个点；
- BRECQ 式 Hessian loss 普遍劣于 MSE，实证支持动机分析；
- 训练开销（单卡 4090，W3A3）：DeiT-S 约 62 分钟，对比 QAT 方法 LSQ 的约 170 小时，且精度更高（68.8 vs 77.3 的差距大幅缩小至反超 QDrop 16 个点）。

## 部署视角

- **最大卖点是"只用 uniform 量化器"**：权重 per-channel、激活 per-tensor 的标准线性量化，直接映射 TensorRT Q/DQ 或任何 INT8 管线，不需要 twin/log√2 等自定义算子；
- GELU→ReLU 是**推理期永久替换**，不是校准技巧——换来的是更容易量化的激活分布和 GELU 算子本身的消失（与 FC1 融合），端侧 NPU 上对 GELU 支持差的平台尤其受益；
- 代价是校准成本：1024 张校准图 + 两次 20000 迭代的 block-wise 重建，属于 PTQ 里偏重的一档，但相比 QAT 仍是几个数量级的差距；
- APH 的思想（蒸馏损失 + 数值 Hessian 估计 + 跨样本平均）可以推广到任意需要"输出重要性加权"的重建场景，不限于 ViT。
